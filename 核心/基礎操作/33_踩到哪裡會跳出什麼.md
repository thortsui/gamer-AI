章節: §6-8 踩到哪裡會跳出什麼（觸發區與 UI 的因果）
適用: 全部
---

【很多 UI 不是「點」出來的，是「站」出來的】（2026-09-18 使用者交代的基礎操作）
你一直卡在外面，很大一部分原因是：你把每個畫面都當成「找按鈕來點」。
但這類遊戲裡有一半的入口是**地上的觸發區**——你走上去，UI 才會自己跳出來；
你人不在上面，那顆按鈕本來就不會有反應，點幾百次都一樣。

**常見的觸發區長這樣**（地面上、通常會發光或有顏色）：
- 發光的方板、白色／黃色的圈圈、地上的箭頭與腳印
- 門口、電梯裡面、平台、傳送墊
- 寫著字的看板**旁邊的那塊地**（看板是說明，地板才是開關）

**怎麼分辨「該點」還是「該站」**
1. 畫面上的字就是線索：寫著「踩踏板」「站上去」「進入」「Enter」的，通通是要你**走過去站上去**。
2. 按鈕點了三次沒反應 → 停手。**改成用走的**：走到那個東西的正下方／正前方，站一兩秒看畫面。
3. UI 跳出來之後**不要走開**——很多觸發區是「離開就關掉」。要點它就站著點。

**站上去之後才點得到**
UI 出現時如果滑鼠點不動，先確認你是不是被鎖在第一人稱（畫面中央有準心）：
用 `{"t":"scroll","v":-3}` 拉遠變第三人稱，游標才會解鎖。

**每學到一條就記下來**（這是最值錢的東西，因為它不會變）
```
{"t":"記因果","做了":"走到發光方板上站著","發生":"跳出下一步的視窗"}
```
把它連同位置一起釘起來更好用：
```
{"t":"標點","name":"傳送踏板","樣子":"地上白色發光方板","前":2}
```
之後每一輪你都會看到它在你的哪個方向、多遠；要用的時候走過去站上去就行。

**驗證的方法只有一個**：走上去 → 看畫面有沒有變 → 有變就是它、沒變就不是。
用 `{"t":"wait","d":1.0}` 停一秒再判斷，不要走過去馬上又走開——很多觸發區要站滿一下才生效。

**卡在外面的徵兆**：你在同一區繞很久、按鈕點不動、畫面完全不變。
這時候該做的不是再點一次，是**低頭看地板**：附近有沒有發光的板子、圈圈、箭頭、門口的墊子。

【看到「框框」或「幾/幾」的地方，就是開場的地方】（2026-09-25 使用者交代）
在大廳或場景裡，只要看到下面兩種東西，那裡就是**開始遊戲的地方**：
- **框框**：地上或空中畫出來的一個框、一塊圈起來的區域（常常會發光或有顏色）。
- **「幾/幾」**：像 `0/4`、`1/6`、`2/8` 這種數字（通常寫在框的上方或旁邊），是現在有幾個人、最多幾個人。
看到了就**走過去、站進框裡**，等它開始。這就是進場的路，不用去按選單、也不用關什麼面板。
（這跟遊戲頁面「伺服器清單」上的人數不一樣：那是還沒進遊戲時挑伺服器用的；這裡講的是**已經在遊戲裡面**看到的框和數字。）
