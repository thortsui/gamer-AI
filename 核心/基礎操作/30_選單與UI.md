---
章節: §8 遊戲內選單（Esc）
適用: 全部
---

【每一輪先確認有沒有 UI 開著】
動作之前先看一眼：畫面上有沒有蓋著一塊面板／視窗／選單／對話框？
有的話，**先把它關掉**，不然你按什麼、走什麼都不會有反應（很多次「按了沒用」都是這個原因）。
關 UI 的優先順序：
  1. **先找叉叉（X）**——通常在那塊面板的右上角，點它最乾淨。
  2. 面板上有寫「關閉／返回／繼續」的按鈕，就點那個。
  3. 點面板以外的空白處。
  4. **esc 放到最後**——esc 是開關，按了可能反而又打開別的選單，而且很容易變成一直按。
關掉之後再看一次畫面確認真的關了，才繼續做事。

【選單怎麼關掉】
esc 是**開關**：按一下開選單、再按一下關。所以選單開著的時候一直按 esc，
等於自己把它開開關關，永遠出不來（你今天在這裡浪費了幾百輪）。
選單開著的時候：**看選單下方或按鈕上寫的字**，它會直接告訴你哪個鍵對應什麼
（例如「繼續」「離開」「重生」，前面會標對應的按鍵）。想繼續玩就選「繼續」，
要離開這場就選「離開」。用滑鼠點按鈕，或按它標示的那個鍵。
點選單以外的空白處通常也能關掉。

【Roblox 好友選單（上面一排好友、底部有「離開」「重生」「繼續」）怎麼關】（2026-10-03 使用者定）
這塊就是 esc 打開的 Roblox 系統選單，不是遊戲的面板。
- 要回去玩：**按一次 esc**（只按一次，按完看畫面），或點底部的「繼續」。
- **不要點「離開」**——點了會跳出「確定要離開遊戲？」，你不是真的要走就點「不要離開」，然後再按一次 esc 關掉選單。
- 10/03 早上你在「好友選單 → 點離開 → 確定要離開？ → 又回選單」繞了半小時，就是因為一直點「離開」又不離開。

【點了沒反應，先當作「你沒按好」，不要當作「這個不能按」】
同一個按鈕**至少多試幾次**再放棄。常見的沒按好：點偏了（點到按鈕邊緣）、
按太短、畫面還在切換就按下去了、上面蓋著另一塊看不太出來的面板。
再試的時候換一點做法：點按鈕正中央、稍微偏一點再點、按久一點、等畫面穩定一秒再點。
試了幾次都完全沒反應，那才是真的不能按，換別的做法。

【第一人稱的時候滑鼠會被遊戲吃掉——但先試一下十字能不能點】
第一人稱時滑鼠通常被鎖在畫面中央當準心用，這時候點畫面上任意位置的按鈕常常點不到。
**但有些遊戲就是拿那個十字當滑鼠**（2026-09-23 使用者教的基礎知識）：轉視角把十字對到按鈕上、
按左鍵（`{"t":"click","x":0.5,"y":0.5}`），按鈕就會有反應。所以順序是：
1. 先把十字對準按鈕按一次左鍵——有反應就是這種模式，以後都這樣點。
2. 沒反應才是真的被鎖住：把鏡頭拉遠變成第三人稱（滾輪／中鍵縮放），或把那個介面關掉再開一次，再去點。
3. 拉遠幾次都解不開、按鈕怎麼都按不動，就是「同一個狀況卡住」，直接退出重進（見「卡住就自己重開遊戲」）。

【還在學這隻遊戲的時候：UI 要一個字一個字讀完再動】
教學視窗、提示框、彈出來的說明——**那是這個遊戲唯一會主動教你的東西**，
關掉就沒有第二次了。學習階段看到任何面板，先做這三件事再決定要不要關：
1. 把上面的字**整段讀完**（用【畫面上的字】那一段，它比你用看的準）。
2. 讀到「按什麼鍵會怎樣」「先做什麼再做什麼」就當場記下來（記因果／列步驟）。
3. 確定沒有東西要記了，才關掉它。

**不要為了「趕快開始」就連點關閉**。急著關掉教學，等於把別人願意告訴你的答案丟掉，
後面你要自己試幾百輪才試得回來。

【看得到不等於點得到】
遊戲視窗有可能比螢幕大、或有一部分在螢幕外。那種時候畫面**照樣看得到**那一塊，
但**滑鼠到不了**——你點幾百次都不會有反應，而且那不是你操作不好。
程式會在【碰不到的區域】那一段照實告訴你哪幾塊點不到，也會直接擋掉點在那裡的動作。

看到那一段有東西的時候，不要再對著那塊硬點。自己想別的辦法，例如：
- **用鍵盤**：Enter／空白鍵／數字鍵／Esc／方向鍵，很多 UI 都有鍵盤對應。
- **走過去互動**：3D 世界裡的東西常常可以走近按 E，不必點 UI。
- **讓它換位置**：捲動清單、關掉再開、換一個入口，把目標弄到畫面中間可碰得到的區域。

【一次只做一件事，一次只按一個鍵】
**不要連點，也不要一輪塞好幾個動作。**
連點很容易誤觸：畫面在切換的途中你又點下去，那一下會落在**新畫面的別的東西**上——
本來要點「開始」，結果點到旁邊跳出「離開確認」，你反而要多花好幾輪把它關掉。
一輪同時送「轉視角＋走路＋點擊」也一樣：畫面在你點的時候已經不是你看到的那個畫面了。

正確的節奏是：
1. **送一個動作**（一個鍵、或一次點擊）。
2. **等畫面穩定**（需要的話送 `{"t":"wait","d":1.0}`）。
3. **看結果**：畫面上的字、按鈕、場景有沒有變。
4. 有變 → 照新畫面決定下一步；沒變 → 才換做法再試一次。

**做完一件事再做下一件**。一輪做三件事看起來比較快，但你會分不出是哪一件造成的結果——
分不出來就學不到東西，而且錯了要花更多輪去解。

【按鈕簿：同一顆按鈕點第二次，就把位置記起來】（2026-09-18 使用者定的基礎規矩）
你每天要點的就是那幾顆按鈕（開始、關閉、確認、知道了）。它們的位置**不會自己跑掉**，
所以第一次點到之後就不該再找第二次——**找一次、記一次、之後照抄**。

程式已經幫你自動記帳：你每點一下，它會看畫面有沒有變，然後把
「名字 → 座標 → 有反應／沒反應幾次」寫進按鈕簿，每一輪回灌給你，長這樣：
```
✅ 開始遊戲：(0.43,0.05)　在「大廳」　有反應 3 次
⚠ 左邊圖示：(0.05,0.30)　有反應 0 次／沒反應 2 次
```
- **✅** ＝ 這個座標成功過三次以上，可靠，直接用。
- **⚠** ＝ 你在那裡點了很多次都沒反應。**那不是按鈕，或者現在不能按**——
  換做法（先關掉擋住的東西、先拉遠解鎖滑鼠、換個入口），不要再點同一個位置。

你自己也可以寫，尤其是程式取不到名字的時候：
```
{"t":"記按鈕","name":"開始遊戲","x":0.43,"y":0.05,"畫面":"大廳","效果":"跳出選地圖"}
```
x／y 不寫就用你**上一次點的位置**；`效果`寫「按下去會發生什麼」，以後就知道該不該按它。

**為什麼要記**：座標用猜的，每次都差幾十像素、每次都落在按鈕外面；
記過的座標是**你自己驗證過真的有反應**的那一點。你一天省下來的那幾百輪，就是這樣省的。

【按完每一顆 UI，一定要讀字】（2026-09-20 使用者定的規矩）
**按下去不是結束，讀字才是。**每一顆按鈕按完，畫面上的字一定會變——
多出來的字就是它打開的東西，不見的字就是它關掉的東西。**那行字裡通常就寫著你下一步要按什麼。**

程式現在會自動幫你比對：你按完一顆按鈕，下一輪提示的**最上面**會出現
```
🔎 你剛才按了「開始」→ 多出來的字：（新出現的那幾個字）。先讀完這些新字再決定下一步
```
或者
```
🔎 你剛才按了「開始」，畫面上的字完全沒變——那一下沒有生效。
```
**反射輪也看得到這一行**，所以沒有藉口不讀。

看到之後只有兩種正確反應：
1. **字變了** → 讀那些新字，**照著它走下一步**（新出現的「確認」「下一步」那類字就是下一顆要按的）。
   不要按完一顆就回頭重按第一顆——那等於把自己打開的門又關上。
2. **字沒變** → 那一下沒生效。**不要再點同一個位置**。換做法：
   先 `scroll -3` 拉遠解鎖滑鼠、先關掉擋住的面板、或走到地上的觸發區站上去。

【每一顆 UI 都要知道它對應什麼功能】
按鈕簿（每輪回灌）除了座標與成功次數，現在還會記下**這顆會跳出什麼**：
```
✅ 開始：(x,y) 在「大廳」 會跳出：（新出現的字）  有反應 N 次／沒反應 M 次
```
這就是你的 **UI → 功能對照表**。你自己也可以補：
`{"t":"記按鈕","name":"確認","x":0.5,"y":0.75,"效果":"按了之後畫面切換"}`

**一顆按鈕的價值不在它的座標，在你知道它會帶你去哪。**

【認識 Roblox 自己的面板：好友選單、玩家列表、esc 選單】（2026-09-26 使用者交代）
畫面上會蓋住你的面板有兩種來源，先分清楚是**遊戲的**還是 **Roblox 自己的**：
- **遊戲的面板**：跟這款遊戲有關的字（任務、商店、職業、開始、確認…），關法看它自己的叉叉或按鈕。
- **Roblox 自己的面板**：每一款遊戲都長一樣，跟遊戲內容無關，**不會幫你推進任何事**。常見三種：
  1. **好友選單／玩家個人卡**：中央一塊面板，上面是某個玩家的名字、頭像或人偶，
     有「加好友」「檢視個人資料」「封鎖」「檢舉」這類按鈕。
     **你點到別的玩家（人偶或名字）就會跳出來**，這是最常見的原因；走近人群亂點就會一直開。
  2. **玩家列表**：一排玩家名字、頭像、分數，通常在畫面右上或整片蓋住。
  3. **esc 選單**：左側一排「玩家、設定、協助、帳號…」的分頁，右下角有「繼續」（或寫著 Esc 繼續）。

**怎麼關（照這個順序，一次一招，關掉再做下一件事）：**
1. 面板**右上角的叉叉（X）**——好友選單、個人卡一定有。
2. 面板上寫「繼續」「關閉」「返回」的字——esc 選單用右下角「繼續」。
3. **esc 按一下**（只按一下；它是開關，第二下又打開）。
4. 點面板以外的空白處。
關掉之後**看一眼畫面確認真的不見了**，沒不見就換下一招，不要對同一個座標連點。

**兩個容易犯的錯：**
- 把 Roblox 的面板當成遊戲的入口，在裡面找「開始」「職業」——裡面沒有，那是 Roblox 的東西。
- 常駐在畫面邊緣的按鈕列（左側一排小圖示、上方的名字與數字）**不是遮罩**，不用關，也關不掉；
  只有**蓋在中央、擋住 3D 畫面**的那塊才是要關的面板。

**怎麼不要一直打開它：** 在人多的地方不要對著玩家點左鍵；要點畫面上的按鈕之前，先用【畫面上的字】確認
那個位置是按鈕的字，不是某個玩家的名字。
