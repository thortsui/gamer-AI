# 專案結構（2026-09-14 起）

他登入一個遊戲時，載入的只有三樣東西：**基礎操作 + 學習模組 + 那個遊戲的專案**。
別的遊戲的知識不會混進來。

```
核心/                     ← 每個遊戲都載入，換遊戲照用
  共用/                   ← 身分、我還是玩家嗎、鐵律與輸出格式
  基礎操作/               ← 怎麼動、怎麼看、怎麼互動（跟哪個遊戲無關）
  學習模組/               ← 怎麼學會一個新遊戲（五階段、計分、檢討、空間感、查資料）
專案/
  動物醫院/
    提示/                 ← 只有這個遊戲要用的（櫃檯、報到課程、理智與物品）
    工作流程/             ← 他自己走出來的步驟（報到、治療、喝咖啡、開始上班…）
    記憶/                 ← 他累積的一切：地圖、互動點、站位、檢討、獎懲、日誌
    素材/                 ← 截圖、YOLO 標註、存檔（很大，不進記憶）
  <下一個遊戲>/           ← 照同樣的四層開一個就好
_封存/                    ← 砍掉但留著的（舊架構、YouTube 時期的東西）
```

## 核心/基礎操作（12 份）

`10_你在哪與進入遊戲`／`20_移動與走位`／`21_視角`／`22_互動按E`／
`24_死亡重生與離開遊戲`／`26_空間感與距離`／`27_轉頭與貼牆為什麼會卡死`／
`28_變色與新增物品`／`30_選單與UI`／`31_讀畫面上的字`／`50_眼睛與工具`／`90_動作表`

判準：**換一個遊戲照樣成立**的操作知識。視角怎麼修、E 怎麼按、YOLO 怎麼用、動作表有哪些。

## 核心/學習模組（7 份）

`05_新遊戲通用準則`（五階段課程）／`06_快思與慢想`／`07_目標懲罰與卡住`（計分制）／
`08_任務分數制`／`11_任務目標與線索`／`29_地圖印證與探索`／`60_學習與查資料`

判準：**怎麼學會一個沒玩過的遊戲**。課程、計分、檢討、探索方法。

## 核心/共用（3 份）

`00_身分與現在的任務`／`25_我還是玩家嗎`／`99_鐵律與輸出格式`

## 專案/<遊戲>/提示

只有玩這個遊戲才有意義的。動物醫院目前 5 份：
`23_物品與理智`／`40_櫃檯_先認識佈局`／`41_櫃檯_東西怎麼記`／`42_櫃檯_作業中`／
`43_報到課程`／`00_本業與這一班`／`07_這個遊戲的分數`／`09_任務樹`／`90_櫃檯專屬動作`
（後四份是 2026-09-15 從核心搬回來的——核心只留每個遊戲通用的）

## 要開一個新遊戲的專案

```
專案/<遊戲名>/
  提示/        ← 可以留空，先靠核心玩
  工作流程/    ← 可以留空，他會自己列步驟
  記憶/        ← 程式會自動建
  素材/        ← 程式會自動建
```
然後 `python flow_agent.py --game <遊戲名>`。核心那三區自動帶過去，
五階段學習課程會從第 1 關（認識遊戲身分）重新跑一輪。

## 程式怎麼找這些檔案

- 提示：`CORE_DIRS`（核心三區）+ `專案/<遊戲>/提示`，依檔名排序後合併
- 工作流程：`專案/<遊戲>/工作流程`
- 記憶（`self.dir`）：`專案/<遊戲>/記憶`
- 三者都有**舊路徑退路**（`提示/`、`工作流程/`、`資料/<遊戲>/`），舊專案不用手動搬

改任何 `.md` 檔**下一輪就生效**，不用重開代理。


## 千萬不要污染核心（2026-09-15）
`核心/` 是每個遊戲共用的。**任何一隻遊戲的內容都不准寫進核心**：
地名、路線、步驟、那隻遊戲的機制與名詞，一律放 `專案/<遊戲>/`。
提示裡也對他講了同一條規則（`核心/共用/99`）。

## 換遊戲要準備什麼
1. `專案/<遊戲>/` 底下開四個資料夾：`提示`／`工作流程`／`記憶`／`素材`。
2. 放一份 `專案/<遊戲>/遊戲.json`：
   - `places`：placeId → 場景名（從 Roblox log 的 `Joining game ... place N` 讀得到），
     沒填就不做「進錯遊戲」的判斷與救援。
   - `大廳place`：進錯遊戲時用深層連結送回哪裡。
   - `詞彙`：YOLO 一開機就盯的英文詞。
   - `模組`：這些是**動物醫院專屬**的功能，新遊戲一律 false——
     `櫃檯`（記櫃檯／掃視櫃檯／櫃檯面板）、`輪班計畫`（這一班的計畫）、
     `報到課程`（6 關課程）、`理智`、`學習課程`（五階段課表）、`任務樹`（寫死的中任務清單）。
3. 提示只放這隻遊戲**真的需要**的。全新遊戲就一句話：「這是一隻全新的遊戲，沒有攻略，自己研究。」
4. 啟動：`python flow_agent.py --game <遊戲>`。
