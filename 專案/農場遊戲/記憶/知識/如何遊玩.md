# 如何遊玩（我自己整理，10/04 20:10）

- 走前用dx把框對到畫面正中央，帶g一次w走滿2.5秒到框邊；停送換快思，每輪必有動作
- 先對正加工機木箱排，一次走滿到旁邊，見E提示才按E讀新字
- 框<0.1且無E＝遠處不可互動，跳過改走東面木箱排加工機；走前確認第三人稱、選單蓋住先關，一次對正方向走滿
- E無效就停：改走過去站旁邊看新提示；無E提示不按E，改點UI或換入口
- 走一步看框變大才繼續；框沒變大＝被擋，改a/d橫移繞牆再走；E提示沒出現就不按；關選單只按一次esc，見繼續按鈕消失就停手
- E無提示硬按無效，見E才按，兩次無效即停手改點字或走旁
- E兩次無效即停手改點字或走旁；量比例失敗換正對牆處再量，同一工具失敗兩次就換
