# 我自己的遊戲手冊（10/04 10:12 自己整理）

## 基礎操作
- dx100=11度，dx3200=一圈360度
- E無提示絕不按；見E才按，按兩次無效即停手改走位
- 同一動作畫面沒變兩次就換做法，不重複同一招
- 面板蓋住先點右上角紅叉或繼續關掉，再做事
- 走過去一次送w≥1.5秒按滿，禁止拆成多次短按
- 對正目標與走過去合併同一輪送，走完看框變大才停
- 點完按鈕下一輪畫面沒變＝沒生效，立刻再點或改走位，不送wait
