# 我自己整理的遊戲手冊（給以後的自己看）

## 這是什麼遊戲

一個 Roblox 遊戲，核心玩法是：準備期蓋防禦牆擋僵尸，戰鬥期射擊僵尸賺金幣。畫面中有血條、理智條、物品欄、計時器。場景包含大廳（有開始遊戲按鈕、試煉按鈕、商店圖標）、射擊靶場（有靶子、武器展示）、以及正式對局地圖。死亡畫面有 Robux 復活按鈕（禁按）和倒數計時。

## 怎麼玩（我已經驗證過的）

### 進入對局的完整流程

1. 在大廳畫面，**先滾輪 scroll 拉遠成第三人稱**，讓滑鼠解鎖（第一人称時滑鼠被鎖，點了沒反應）。
2. 確認畫面頂部中央有綠色長條按鈕，文字是「開始遊戲」或 OCR 讀成「用始避战」，**座標中心約 (0.5, 0.05)**。點它。
3. 點完等 1～2 秒，看畫面是否切換。如果出現「傳送中」字樣，代表正在載入地圖。
4. 如果畫面出現地圖選擇面板（下方有綠色長條按鈕），**點下方綠色「開始出發」按鈕，座標約 (0.5, 0.76)**。
5. 進入局內後，右上角會出現任務提示，例如「準備期 — 快蓋防禦牆！剩 X 秒」或「新殭屍出現!」。

### 移動操作（實測數值）

- **前進**：一次按 `w` 按住 **1.5 秒**走到底，不要拆成多次短按。
- **後退**：按 `s`。
- **橫移**：按 `a`（左）或 `d`（右）。
- **貼牆時**：先按 `a` 或 `d` 橫移 **0.6 秒**離開牆面，確認前方有空，再按 `w` 1.5 秒直走。
- **轉視角**：滑鼠拖 dx 100 = 左右轉 24 度；滑鼠拖 dy 100 = 上下轉 20 度。每度機械量：dx 4.17 / dy 5.06。
- **低頭修正**：如果鏡頭低頭 N 度，送 `dy = -N × 5.06` 修回水平。例如低頭 16 度送 dy -54，低頭 32 度送 dy -108，低頭 50 度送 dy -253。
- **卡住時**：先 scroll 拉遠解鎖滑鼠，再操作。

### 互動操作

- **物品欄**：按數字鍵 1～9 拿取物品。
- **互動提示**：畫面出現 `E` 字樣時，長按 `E` 約 1.5 秒互動。互動前必須確認 `E` 提示落在畫面準心附近。
- **射擊**：對準目標後左鍵射擊（靶場中多次試射未確認是否生效，需再驗證）。

### 死亡與復活

- 理智歸零 = 死亡。
- 死亡畫面有 Robux 復活按鈕，**禁按**。
- 死亡後等倒數自動結束，自動回大廳。

### 遊戲循環（從任務提示與 wiki 得知，部分未實測）

- 打殭屍賺金幣 → 商店買道具 → 蓋方塊防禦牆 → 躲堡射殭屍。
- 準備期快蓋防禦牆，戰鬥期射殭屍。
- 咖啡可補理智（位置待確認）。

## 下次進去先做什麼

1. **修視角回水平**：如果鏡頭朝上或朝下，先送 dy 修正到水平（低頭 N 度送 dy = -N × 5.06），確認能看到地面與前方場景。
2. **scroll 拉遠解鎖滑鼠**：滾輪拉遠成第三人稱，讓滑鼠解鎖，才能點 UI 按鈕。
3. **點開始遊戲按鈕 (0.5, 0.05)**：點一次後等 2 秒，確認畫面有變化（出現「傳送中」或場景切換）才繼續下一步；如果沒變化，改按 Enter 或改點右側試煉按鈕，不要重複點同一座標超過兩次。
