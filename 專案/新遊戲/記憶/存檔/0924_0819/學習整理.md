# 我自己的遊戲手冊（09/24 07:50 自己整理）

## 基礎操作
- scroll v-3 拉遠解鎖滑鼠，才能點 UI 按鈕
- dx 100 轉 20 度 (每度 5px)，dy 100 轉 8 度 (每度 12.5px)
- 低頭 16 度送 dy-54 回水平
- 低頭 32 度送 dy-108 回水平
- 低頭 50 度送 dy-253 回水平
- 點字開始遊戲用 OCR 框中心，勿估座標
- 開始遊戲按鈕中心約 (0.5, 0.05)
- 開始出發按鈕中心約 (0.5, 0.76)
- 教學面板知道了按鈕約 (0.5, 0.883)
- 卡住時先 scroll -3 解鎖，再點字或按 Enter

## 遊戲模式
- 大廳點開始遊戲 -> 選地圖 -> 開始出發
- 準備期提示：準備期 — 快蓋防禦牆！
- 遊戲結束或死亡後等倒數自動回大廳
- 死亡畫面有 Robux 復活按鈕，嚴禁點擊

## 地圖
- 目前僅知關卡出生點，需探索其他區域
- 場景看板轉頭會跟著動，非 UI 按鈕
- 需標記可互動踏板與牆壁作為參考點

## 如何遊玩
- 進場後先確認第三人稱且視角水平
- 準備期快速蓋牆，戰鬥期移動避敵
- 卡住時退出重進：esc -> l -> enter
- 重進前比對遊戲名稱與封面

## 目標
- 生存並完成關卡任務
- 避免死亡，死亡不扣分但需檢討
- 探索地圖並標記關鍵位置

## 異常與危險
- 死亡後等待自動重生或回大廳
- 遇敵靠近時優先移動閃避
- 畫面全黑或卡住超過兩分鐘退出重進

## 資源與物品

- 咖啡與道具位置待探索
- 理智值補給方式待驗證
