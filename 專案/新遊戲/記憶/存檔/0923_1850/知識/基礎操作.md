# 基礎操作（我自己整理，09/23 18:23）

- 滑鼠拖 dy 100 轉 8 度，全程 178 度需 dy 2100
- 滑鼠拖 dx 100 轉 20 度，一圈 360 度需 dx 1800
- 每度刻度：dx 5.0 / dy 11.8 (機械實測)
- scroll v-3 拉遠變第三人稱，解鎖滑鼠才能點 UI
- scroll v3 拉近變第一人稱，滑鼠被鎖中央
- 低頭 16 度送 dy -54 回水平，同輪 scroll -3
- 低頭 32 度送 dy -108 回水平
- 低頭 50 度送 dy -253 回水平
- 長按 E 互動約 0.45 秒生效
- 卡住退出：esc -> l -> enter -> 藍色箭頭重進
