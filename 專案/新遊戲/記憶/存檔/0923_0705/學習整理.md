# 我自己的遊戲手冊（09/23 06:47 自己整理）

## 基礎操作
- scroll -3 拉遠解鎖滑鼠，第三人稱才能點 UI
- dy 100 轉 179 度；dx 100 轉 26 度（每度 dx 3.9, dy 0.56）
- 低頭 16 度送 dy -54 回水平
- 低頭 32 度送 dy -108 回水平
- 低頭 50 度送 dy -253 回水平
- 點字用 OCR 框中心，不估座標
- 長按 E 互動約 0.45 秒
- 轉頭會跟著動的是場景，不是 UI

## 遊戲模式
- 大廳頂部中央有「開始遊戲」按鈕
- 開始遊戲按鈕 OCR 框中心約 (0.44, 0.05)
- 開始出發按鈕在下方綠色長條，約 (0.5, 0.76)
- 教學面板「知道了」在下方綠色 (0.5, 0.883)
- 點開始遊戲後跳出地圖選單，再點開始出發
- 右上角出現「準備期」代表進入關卡
- 死亡畫面有 Robux 復活按鈕，禁按，等倒數結束回大廳

## 地圖
- 大廳：有開始遊戲按鈕與教學面板
- 關卡出生點：進入後的第一個位置
- 準備期顯示「快蓋防禦牆」提示

## 如何遊玩
- 1. 大廳 scroll -3 拉遠解鎖滑鼠
- 2. 修平視角（看水平儀，一次送完 dy）
- 3. 點字「開始遊戲」（OCR 框中心）
- 4. 等地圖選單出現
- 5. 點字「開始出發」（下方綠色長條）
- 6. 進入關卡，準備期蓋防禦牆
- 7. 生存至倒數結束或死亡回大廳

## 目標
- 成功進入關卡 +30 分
- 在關卡內互動成功 +10 分
- 避免死亡、避免亂走扣分
- 完成遊戲任務（如蓋防禦牆）得分

## 異常與危險
- 滑鼠被鎖（第一人稱）點不到 UI，需拉遠
- 低頭看地板會迷路，需修回水平
- 點按鈕無效時檢查是否滑鼠被鎖或 UI 被擋
- 卡住時先重試上一動作，無效再換做法
- 死亡後等自動回大廳，勿按付費復活

## 資源與物品
- 物品欄用數字鍵 1-9 切換
- E 鍵互動（0.45 秒）
- 無明確理智補給機制（待驗證）
