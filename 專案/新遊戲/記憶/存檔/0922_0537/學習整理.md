# 我自己的遊戲手冊（09/22 05:13 自己整理）

## 基礎操作
- 第三人稱解鎖滑鼠：scroll -3，確認看到背影後才能點UI
- 視角修正：dy 100轉30度，低頭16度送dy-54回水平
- 水平視角：保持水平，低頭看地板會迷失方向感
- 點擊UI：優先使用點字(OCR框中心)，避免手動猜座標

## 遊戲模式
- 進場流程：大廳 -> 點開始遊戲 -> 選地圖 -> 點開始出發 -> 進關卡
- 開始遊戲按鈕：頂部中央(0.5, 0.05)，需第三人稱解鎖後點擊
- 開始出發按鈕：地圖面板下方綠色長條(0.5, 0.76)
- 教學面板：點擊下方綠色「知道了」(0.5, 0.883)關閉
- 死亡處理：等待倒數結束自動回大廳，嚴禁點擊Robux復活按鈕

## 地圖
- 大廳：進場入口所在，有開始遊戲按鈕
- 關卡出生點：進入遊戲後的初始位置，需立即移動避開
- 場景看板：轉頭時跟著動的為場景物件，非UI按鈕，勿點擊

## 如何遊玩
- 進場：scroll拉遠 -> 修平視角 -> 點開始遊戲 -> 點開始出發
- 開局：進場後立即移動(WASD)離開出生點，避免站樁被圍
- 任務：關注右上角任務提示(如準備期、蓋牆)，依指示行動
- 互動：看到E提示再按E，無提示勿空按互動鍵

## 目標
- 主要目標：成功進入關卡並存活，完成遊戲任務
- 得分機制：成功進場+30，互動成功+10，亂走/空按扣分
- 禁忌：嚴禁購買/復活等花錢行為，嚴禁無目的亂走

## 異常與危險
- 卡住：同一動作兩次無效，立即換做法或重開遊戲
- 面壁：臉貼牆時，後退(s)或橫移(a/d)離開，再轉頭
- 死亡：進場秒死多因站樁，需先移動再思考，事後看回放
- UI卡死：若按鈕無效，檢查是否被鎖在第一人稱，解鎖後重試

## 資源與物品
- 物品欄：數字鍵1-9切換，左鍵使用/E互動
- 理智/血量：關注HUD數值，低時尋找補給或避戰
