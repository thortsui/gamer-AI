# 我自己的遊戲手冊（09/22 22:18 自己整理）

## 基礎操作
- 第三人稱解鎖滑鼠：scroll v-3 拉遠，確認準心消失
- 低頭修平：dy = 低頭度數 × 3.4 (例:低頭16度送-54)
- 抬頭修平：dy = 抬頭度數 × 3.4 (例:抬頭30度送+102)
- 水平儀驗證：送dy後看度數變化，非畫面感覺
- 點UI前必確認：無遮擋面板 + 第三人稱(滑鼠自由)

## 遊戲模式
- 大廳 -> 點開始遊戲 -> 地圖選單 -> 點開始出發 -> 關卡
- 準備期：右上角顯示「準備期...剩X秒」，需蓋防禦牆
- 戰鬥期：敵人來襲，需生存/互動
- 結束：死亡或時間到，自動回大廳
- 測試場/練習場：禁止進入，直接繞開

## 地圖
- 大廳：有「開始遊戲」按鈕(頂部中央)
- 關卡出生點：進入後初始位置，需快速移動離開
- 防禦牆位置：準備期需互動蓋牆的地點(待驗證)

## 如何遊玩
- 1. 大廳：scroll -3解鎖 -> 點字「開始遊戲」
- 2. 選單：點字「開始出發」(下方綠色)
- 3. 進場：立即移動(w/a/d)離開出生點，避免秒死
- 4. 準備期：找防禦牆互動(需E提示)
- 5. 戰鬥：生存/完成任務，看HUD狀態

## 目標
- 成功進入關卡並存活
- 完成準備期防禦任務
- 生存過戰鬥期
- 獲取遊戲內資源/分數(待驗證)

## 異常與危險
- 秒死：進場後站著不動會死，必須先移動
- 滑鼠鎖死：第一人稱時點不到UI，需拉遠
- 面板遮擋：有彈窗時先關掉再操作
- 禁止按鈕：Robux復活、購買、升級等付費項
- 卡住：同一動作3次無效，換做法或重開遊戲

## 資源與物品
- 物品欄：數字鍵1-9切換
- 互動：有E提示時按E(1.5秒)
- 理智/血量：看HUD狀態條(位置待驗證)
