# 我自己的遊戲手冊（09/24 05:09 自己整理）

## 基礎操作
- 第三人稱解鎖滑鼠後才能點UI，需先scroll -3拉遠
- 開始遊戲按鈕位於頂部中央，OCR框中心約(0.5, 0.05)
- 開始出發按鈕位於下方綠色長條，OCR框中心約(0.5, 0.76)
- 教學面板關閉按鈕在下方綠色，OCR框中心約(0.5, 0.883)
- 水平修正：低頭16度送dy-54，低頭50度送dy-253
- 視角刻度：dx 100轉20度，dy 100轉8度（機械實測）
- 若UI點擊無效，嘗試按Enter鍵啟動或觸發地圖選單
- 互動長按E時間約0.45秒即可生效

## 遊戲模式
- 流程：大廳 -> 點開始遊戲 -> 選地圖 -> 點開始出發 -> 進入關卡
- 準備期提示：右上角顯示「準備期 — 快蓋防禦牆！剩 X 秒」
- 死亡處理：出現Robux復活按鈕時禁按，等待倒數結束自動回大廳
- 加入遊戲前務必比對名稱與封面，避免進錯遊戲

## 地圖
- 大廳為主要集合區，包含開始遊戲按鈕與教學面板
- 關卡出生點為進入關卡後的初始位置
- 場景看板若轉頭會跟著動，代表非UI，應走開而非點擊

## 如何遊玩
- 進入大廳後，先scroll拉遠解鎖滑鼠
- 使用「點字」功能點擊OCR辨識到的「開始遊戲」
- 等待地圖選單出現，點擊「開始出發」
- 進入關卡後，依右上角任務提示行動
- 若卡住超過五分鐘，執行ESC -> L -> Enter重進遊戲

## 目標
- 成功進入關卡並完成任務以獲取分數
- 避免觸碰任何付費（Robux）選項
- 在準備期內完成防禦牆建造
- 存活並完成當前波次或任務目標

## 異常與危險
- 死亡畫面含付費復活按鈕，嚴禁點擊
- 若滑鼠被鎖（第一人稱），點擊UI無效，需拉遠解鎖
- 若同一按鈕點擊三次無反應，檢查是否被面板遮擋或需走觸發區
- 鏡頭頂到天花板或地板時，需依水平儀修正視角

## 資源與物品
- 物品欄使用數字鍵1-9切換
- 咖啡與理智補給品位置待驗證
- 道具使用方式待驗證（左鍵/右鍵/E）

## 還不確定的
- 開始遊戲按鈕精確座標是否為(0.44, 0.05)或(0.5, 0.05)
- 關卡內具體敵人種類與攻擊方式
- 理智補給品具體位置與使用效果
- 任務完成後的具體獎勵與分數計算方式
- 地圖中是否有其他隱藏區域或互動點
