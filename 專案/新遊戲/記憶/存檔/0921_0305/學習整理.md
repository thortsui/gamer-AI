# 我自己的遊戲手冊（09/21 02:30 自己整理）

## 基礎操作
- scroll -3 拉遠解鎖滑鼠才能點 UI
- 低頭修水平：dy = 度數 × 3.37
- 左右轉視角：dx = 度數 × 5.0
- 點字優先於猜座標，用 OCR 框中心
- 點無效先確認是否被鎖第一人稱

## 遊戲模式
- 大廳頂部中央有開始遊戲按鈕
- 地圖選擇後點下方綠色開始出發
- 準備期蓋防禦牆，波次期打殭
- 死亡畫面禁按 Robux 復活按鈕

## 地圖
- 大廳：出生點，有開始按鈕
- 地圖選擇面板：顯示地圖選項
- 關卡：有敵人與防禦區域

## 如何遊玩
- 拉遠解鎖滑鼠 -> 點開始遊戲
- 選地圖 -> 點開始出發 -> 等傳送
- 準備期蓋牆 -> 波次打殭 -> 結算

## 目標
- 成功進場 +30 分
- 走到目標並互動成功 +10 分
- 完成自訂任務拿滿分
- 避免死亡與亂走扣分

## 異常與危險
- 理智歸零會死
- 碰到花錢東西 -300 分
- 原地空轉與面壁會扣分
- 死亡後等倒數自動回大廳

## 資源與物品
- 打殭賺金幣
- 商店買道具與武器
- 蓋方塊做防禦牆
- 躲堡壘射擊殭人
