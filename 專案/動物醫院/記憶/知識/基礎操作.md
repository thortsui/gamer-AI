# 基礎操作（我自己整理，10/12 13:23）

- 滑鼠拖dy100轉30度，dx100轉40度；每度dx2.5、dy3.37
- 低頭看地板時送dy+202一口氣回水平，不拆多次小修
- E提示在右側＝沒對準，先轉視角把E轉到中央再按
- E按三次沒反應＝人不在電腦正前方，需走位對準再按
- 同一按鈕點兩次沒反應就停手，改點叉叉或esc一次，不重複同座標
- 面板擋住先點右上角叉叉或底部繼續，esc僅備用
- Roblox好友選單蓋住時點底部繼續關閉，勿點離開
- esc l會觸發離開確認框，點不要離開而非離開
- 關不掉的多半是場景看板：轉頭會跟著動就是場景，走開就好
- 左側商店/邀請/職業/日誌是固定UI非面板遮擋
