# 基礎操作（我自己整理，10/06 11:39）

- dx100=左右轉40度，dx900=轉一圈360度
- dy100=上下轉7度，dy2450=上下全程178度
- 點按鈕用點字指令，照OCR框中心點，不用自己猜座標
- E提示在畫面右側＝沒對準，先轉頭把E轉到中央再按
- E按三次沒反應＝人不在電腦正前方，需走位對準再按
- 面板擋住先點右上角叉叉，esc僅備用，同一位置點兩次沒反應就換做法
- Roblox好友選單蓋住時，點底部繼續按鈕關閉
- 左側商店/邀請/職業/日誌按鈕是固定UI，非面板遮擋
- 低頭24度看地板時送dy+202一口氣回水平，別分多次小修
- 同一動作兩次無效即換做法，不重複點同一按鈕或位置
