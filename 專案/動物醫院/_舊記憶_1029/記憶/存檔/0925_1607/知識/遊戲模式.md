# 遊戲模式（我自己整理，09/25 15:38）

- 進入前必比對遊戲名稱與封面，防進錯場
- 死亡後點擊「前往大廳」返回
- 任務提示位於右上角（常顯示未讀取）
- 對話框遮擋互動時需先關閉
- 面板遮擋時優先關閉，勿依賴Esc
- Roblox好友選單覆蓋時按Esc關閉
- 聊天視窗遮擋左側時需關閉
- 同一按鈕點擊兩次無反應即換策略
- 任務5分鐘無進展需切換目標
- 卡住時嘗試重進或換區域
- 進入前確認第三人稱與游標解鎖
- 理智過低時確認視角與游標狀態
- 死亡後檢查是否誤觸離開對話框
- 進入前檢查是否有遮擋UI
- 進入前確認遊戲身分
- 進入前確認無遮擋
- 進入前確認游標解鎖
- 進入前確認視角水平
- 進入前確認無卡住
- 進入前確認無死亡
