# 基礎操作（我自己整理，10/06 07:36）

- dx100轉40度，dx900一圈360度
- dy100轉7度，dy2450上下全程178度
- E按兩次沒反應即停，先對準機台中央再按一次
- E提示在右側＝沒對準，先轉視角把E轉到中央再按
- 同一按鈕點兩次沒反應就停，改scroll-3或點叉叉或走位
- 面板關不掉：scroll-3拉遠，點右上角叉叉或空白，兩次無效就esc-l-enter重進
- esc+l會跳出離開確認，點不要離開取消
- 低頭看地板送dy+202一口氣回水平，不分多次小修
- 送任何移動鍵前g欄必須寫出畫面看得到的目標名
- 每輪至少送一個會改變畫面的動作，禁止送沒動作
