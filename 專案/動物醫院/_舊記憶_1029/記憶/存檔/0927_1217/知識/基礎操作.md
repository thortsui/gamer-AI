# 基礎操作（我自己整理，09/27 11:52）

- 面板遮擋先點右上角叉叉，勿連按 esc
- 同一座標點兩次無反應就換做法，不重複同一位置
- 看不到背影先 scroll -3 拉遠＋按 s 後退，dy 保持 0 只用 dx 掃
- 貼牆先按 s 後退 1.5 秒離開牆面，再用 dx 左右掃找開口
- 面板關不掉：scroll -3 拉遠→點叉叉或空白，兩次無效就 esc→l→enter 重進
- 連線中斷面板：重新連線試兩次沒反應就點「離開」回大廳再挑有人的場重進
- Roblox 好友選單覆蓋時按 esc 關閉，不是遊戲選單
- 長按 E 無反應時改用左鍵點擊物件中央
- 對話框遮擋互動需先關閉
