# 我自己的遊戲手冊（09/13 20:29 自己整理）

## 基礎操作
- 滑鼠拖50像素轉約7度，100像素約14度，200像素約27度
- 按w 1秒移動量27，s 1秒移動量100，a 1秒移動量80，d 1秒移動量87
- 互動需先看到E提示，長按E約0.45秒有效，無提示按了無效
- 視角水平時dy填0，僅用dx左右轉，避免上下亂動卡死
- 貼牆時用a/d橫移繞過，極少用s後退，後退易撞後方障礙

## 遊戲模式
- 遊戲開始需在大廳挑選有人數的伺服器加入
- 進入後畫面出現「輪班 N」代表正式開始上班
- 理智歸零即死亡，只能點「前往大廳」免費復活
- 遊戲結束或卡住三分鐘才允許退出重進
- 禁止購買道具或點擊付費按鈕，否則扣分

## 地圖
- 主要區域包含櫃檯窗口、走廊、房間、儲藏室
- 咖啡機位於左前方，咖啡杯在右前方桌上
- 拍照機與拍照區為特定功能區，需靠近互動
- 走廊有門牌（如3-5），需對應房間號
- 地圖座標會漂移，需定期用「我在」校正位置

## 如何遊玩
- 核心循環：窗口報到(Check In) -> 治療病人
- 報到流程：走到櫃檯 -> 對準電腦/文件 -> 互動
- 治療流程：報到滿4人或無病人時 -> 去病房治療
- 任務優先：嚴格執行右上角黑底白字任務提示
- 不要空等，無病人時主動去治療或補理智

## 目標
- 主要目標是撐過輪班並完成報到與治療
- 成功報到與治療獲得高分，死亡與亂走扣分
- 自訂目標需具體可量化，並設定合理時間預估
- 保持理智高於20%，低於則補咖啡
- 避免貼牆、亂走、空按E等無效行為

## 異常與危險
- 異常多為顏色變化、多出或缺少物品
- 需比對本人與資料照片、CCTV差異
- 理智歸零會死亡，需及時補理智
- 手槍等危險物品勿撿，會彈出購買視窗
- 遇到UI遮擋時，優先找叉叉關閉，勿亂按esc

## 資源與物品
- 物品欄數字鍵1-9切換手持物品，非直接使用
- 咖啡機/杯可補理智，需靠近並互動
- 道具使用需先確認手持狀態，再點擊或按E
- 錢幣與升級道具嚴禁購買，僅限免費互動
- 筆記與地圖記憶為重要資源，需定期整理

## 還不確定的
- 具體房間內部佈局與治療步驟細節需驗證
- 不同異常類型的具體處理方式需實測
- 地圖遠端區域的準確座標需進一步探索
- 特定UI按鈕的準確位置與功能需確認
- 多人伺服器下的協作機制與互動細節
