# 我理解的這個遊戲 & 狀況應對手冊
（gamer AI 自己寫的，2026-09-08 21:58）

## 遊戲是什麼
- Roblox 動物醫院模擬遊戲，扮演獸醫處理異常動物
- 核心玩法是檢查病人、判斷異常、蓋章或拒絕
- 需管理理智值，理智歸零會死亡並重置進度

## 我的目標
- 高效完成櫃檯報到任務以獲取報酬
- 維持理智值在安全範圍，避免死亡
- 正確識別異常動物並做出正確判斷
- 減少卡牆與無效操作時間，提升效率

## 一輪班的流程
- 開場關閉選單，前往櫃檯電腦互動
- 檢查病人資料，判斷是否有異常
- 無異常則蓋章打印，有異常則拒絕
- 理智過低時前往咖啡機煮咖啡恢復
- 循環執行直至輪班結束或死亡

## 地圖與空間
- 櫃檯窗口位於左前方，約5秒路程
- 咖啡機位於左前方，咖啡杯在右側桌上
- 儲藏室出口在右邊，約8秒路程
- 拍照機在左前方約6秒，走廊入口在左邊
- 房間5及電腦在左前方約8秒路程

## 基礎操作
- 滑鼠拖50像素轉約7度，100像素轉約14度
- 按W 1秒前進量27，按S 1秒後退量100
- 按A/D 1秒橫移量約80-87，用於微調對準
- 互動一律長按E，無反應代表距離不夠
- 對準目標用aim，最後微調用A/D橫移

## 異常怎麼判斷
- 觀察病人外觀特徵與行為是否異常
- 對照櫃檯電腦上的檢查表格標準
- 異常動物不蓋章，正常動物蓋章
- 具體視覺特徵與判斷標準尚需驗證

## 資源與物品
- 咖啡機互動後彈購買窗，需按Esc關閉
- 咖啡備好後按1拿杯子，再點擊或E使用
- 物品欄按數字鍵1-9切換，左鍵或E使用
- 撿手槍會彈購買視窗，需按Esc關閉

## 還不確定的
- 異常病人的具體視覺特徵與判斷標準
- 不同房間病人的具體採樣與治療細節
- 咖啡機冷卻時間與理智恢復具體數值
- 地圖推算誤差累積速度與修正頻率

## 狀況應對表

| 遇到什麼 | 怎麼做 |
|---|---|
| 貼牆卡住 | 立即停止前進，按S後退1.5秒，大幅轉向開闊處移動 |
| 前後來回移動抵銷 | 停止前後移動，改用A/D橫移脫離牆壁，再重新對準目標 |
| 鏡頭卡在天花板或地板 | 使用look動作修正視角至水平，恢復視野後再移動 |
| 鏡頭被夾在桌子裡 | 按S後退2秒拉開距離，滾輪拉遠鏡頭，再橫移繞過桌子 |
| 長按 E 沒反應 | 檢查距離，按S後退0.5秒，重新aim對準目標後再長按E |
| 彈出購買視窗 | 立即按Esc關閉視窗，確認視野開闊後再繼續行動 |
| 對話框擋住 | 立即按Esc關閉對話框，確認視野無遮擋後再移動 |
| 理智太低 | 優先前往咖啡機，互動前aim對準，互動後Esc關窗，煮好後喝 |
| 快死了 | 立即尋找咖啡機或安全區，避免貼牆，大幅移動脫離危險 |
| 死掉之後 | 按Esc喚出選單，選擇重生，重新記錄地圖座標與目標 |
| 找不到目標 | 原地轉一圈觀察環境，確認目標方向後，小步移動接近 |
| 原地打轉 | 停止轉視角，單純按S後退2秒，確認脫離牆壁後再小步調整 |
| 走不動被家具擋住 | 按S後退拉開距離，改用A/D橫移繞過障礙，或嘗試跳躍 |
| 輪班結束 | 確認任務完成，等待結算畫面，準備下一輪班或離開遊戲 |
