# 我自己的遊戲手冊（09/12 08:42 自己整理）

## 基礎操作
- 滑鼠拖100像素約轉14度，dx 185轉四分之一畫面
- 按w 1秒移動量27，被擋住時變化量為0
- 長按E需0.45秒以上，無反應代表距離不夠或沒對準
- 視角水平時dy填0，僅用dx左右轉，避免上下亂動
- 互動前必須看到畫面上出現E提示，否則按了無效

## 遊戲模式
- 遊戲開始於大廳，需手動選擇人多的伺服器加入
- 進入醫院後上方顯示「輪班 N」才算開始上班
- 理智歸零即死亡，只能點「前往大廳」免費按鈕
- 嚴禁點擊「自我復活」或任何花錢選項
- 死亡或卡住三分鐘才允許退出重進，否則在內解決

## 地圖
- 櫃檯窗口是主要工作區，位於入口附近
- 咖啡機在左前方，咖啡杯在右前方桌上
- 走廊入口通往病房，門牌3-5與5為主要區域
- 拍照區與儲藏室出口為次要互動點
- 地圖座標會漂移，回到熟悉點需重新記位置校正

## 如何遊玩
- 核心循環：窗口報到(Check In) -> 治療病人
- 報到流程：對準文件/電腦 -> 長按E -> 蓋印/登記
- 治療流程：檢查異常 -> 拍照/記錄 -> 治療 -> 結案
- 無病人時去治療已登記病人，不要空等
- 卡住時先後退、橫移繞路，不要原地反覆撞牆

## 目標
- 主要目標：撐過一輪班，完成報到與治療任務
- 計分邏輯：成功互動加分，死亡/花錢/退出重扣
- 理智低於20%時補咖啡，高於20%繼續工作
- 避免貼牆、空按E、誤觸發購買視窗
- 保持視角水平，確保視野開闊以發現目標

## 異常與危險
- 異常多為顏色改變、多出物品或物品消失
- 判斷異常需比對照片、CCTV或資料矛盾
- 理智歸零會死亡，需立即前往大廳重開
- 手槍等花錢物品嚴禁撿取，會彈出購買視窗
- 貼牆卡住時視野受限，需後退轉向恢復視野

## 資源與物品
- 咖啡機在左前方，長按E互動補理智
- 物品欄數字鍵是切換手持，非直接使用
- 手持物品後用左鍵或E使用，再按數字鍵收回
- UI面板遮擋時優先點叉叉關閉，esc為最後手段
- 滾輪在清單中捲動內容，在遊戲中縮放鏡頭

## 還不確定的
- 不同伺服器地圖佈局是否完全一致
- 異常事件的具體觸發條件與頻率
- 治療病人的具體操作步驟細節
- 理智下降的具體速率與咖啡補給量
- 隊友互動對任務進度的具體影響
