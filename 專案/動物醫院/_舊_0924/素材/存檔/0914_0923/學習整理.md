# 我自己的遊戲手冊（09/14 09:14 自己整理）

## 基礎操作
- 滑鼠拖50像素轉約7度，100像素轉約14度，200像素轉約27度
- 按w 1秒移動量27，s 1秒移動量100，a 1秒移動量80，d 1秒移動量87
- 視角水平時dy填0，僅左右轉動；偏上往下修，偏下往上修
- 互動前必須看到E提示，無提示按E無效；需aim對準或靠近
- 長按E需0.45秒以上，無反應代表距離不足需移動靠近
- 卡住時先s後退並轉向，確認視野開闊再移動，避免貼牆
- 滾輪在清單捲動內容，在遊戲畫面縮放鏡頭，非轉視角
- 關UI優先點叉叉或關閉按鈕，最後才用esc，避免誤開選單

## 遊戲模式
- 遊戲開始需在大廳挑選有人數的伺服器加入，確認進入醫院
- 進入後上方顯示「輪班N」代表開始上班，為第一人稱
- 理智歸零（死亡）才可退出遊戲，其他情況禁止自行退出
- 死亡後點擊下方「前往大廳」按鈕，禁止點擊付費復活
- 退出後需重新比對遊戲身分，選擇人多的伺服器重新加入
- 每輪班結束或失敗後，需確認畫面回到大廳再重新進入
- 若連續三分鐘完全無法行動，視為卡死，可退出重進

## 地圖
- 櫃檯窗口為主要工作區，位於醫院入口附近
- 咖啡機位於左前方，咖啡杯在右前方桌上
- 走廊入口連接各科室，門牌標示房間號碼（如3-5）
- 拍照區設有拍照機，用於記錄病人異常
- 儲藏室出口位於醫院後方，非主要工作區域
- 房間內設有電腦，用於登記與治療操作
- 地圖需自行腦中拼湊，依賴記憶走過的相對位置
- 陌生區域先左右掃視，避免上下亂看導致迷失

## 如何遊玩
- 主要任務為Check In（報到）與治療病人
- 窗口有人時優先進行Check In，無人時去治療
- Check In流程：走到櫃檯、開電腦、比對資料、蓋章
- 治療流程：登記後進入房間，按步驟進行治療
- 理智低於20%時去補咖啡，補完立即返回崗位
- 發現異常需拍照存證，並按流程通報或處理
- 嚴格遵守右上角黑底白字任務指示，不自作主張
- 操作時保持視角水平，避免貼牆，保持移動流暢

## 目標
- 主要目標為完成輪班，獲取分數與獎金
- 成功Check In與治療病人可獲得高額分數
- 分數隨時間遞減，動作越快獎金越高
- 避免死亡、亂走、空按E等扣分行為
- 維持理智在安全範圍，避免理智歸零
- 完成自訂目標可獲得額外獎勵，需可驗證
- 每局分數歸零，專注於當前輪班的表現
- 通過實測與筆記優化操作，提升遊戲熟練度

## 異常與危險
- 異常多為顏色變化、多出或缺少物品，非怪物
- 需比對本人與資料照片、CCTV，發現差異
- 理智歸零即死亡，需立即前往大廳重進
- 貼牆、面壁、原地不動會導致扣分與卡住
- 亂走無目的地、空按E、鏡頭頂
