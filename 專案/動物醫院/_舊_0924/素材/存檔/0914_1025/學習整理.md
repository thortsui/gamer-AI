# 我自己的遊戲手冊（09/14 10:09 自己整理）

## 基礎操作
- 滑鼠拖50像素轉7度，100像素轉14度，200像素轉27度
- 按w 1秒移動量27，s 1秒移動量100，a/d移動量約80-87
- 互動需先看到E提示，長按E約0.45秒有效，無提示按了無效
- 視角水平時dy填0，偏上往下修，偏低往上修，幅度要夠大
- 貼牆時用a/d橫移繞過或s後退，避免直撞牆面
- UI開著時先找叉叉關閉，esc為最後手段且易誤開
- 滾輪在清單捲動內容，在遊戲畫面縮放鏡頭，非轉視角
- 物品欄數字鍵切換手持，再按左鍵或E使用，勿重複按數字

## 遊戲模式
- 遊戲開始需在大廳挑選有人數的伺服器加入
- 進入醫院後上方顯示「輪班 N」才算正式開始
- 理智歸零（死亡）或遊戲結束才可退出，否則禁止退出
- 死亡後點下方紫色「前往大廳」按鈕，禁點付費復活
- 重新加入需比對遊戲名稱、作者、封面，確認輪班N
- 卡住時在遊戲內解決（換向、繞路、關UI），勿退出重載

## 地圖
- 櫃檯窗口為主要工作區，位於入口附近
- 咖啡機位於左前方，咖啡杯在右前方桌上
- 走廊有門牌3-5及5，通往各房間
- 房間5內有電腦，拍照區設有拍照機
- 儲藏室出口位於特定區域，需探索確認
- 地圖需腦中拼湊，走到熟悉處需重新記位置校正
- 異變常為顏色變化或物品增減，需比對照片/CCTV

## 如何遊玩
- 主要任務為Check In（報到）與治療病人
- Check In流程：走到櫃檯，長按E開電腦，比對資料
- 治療流程：登記後前往病房，執行治療動作
- 理智低於20%時去補咖啡，補完立即回崗位
- 遇到異常先拍照存證，比對後通報或處理
- 操作順序：確認UI關閉->確認視角水平->對準目標->互動
- 卡住時換做法：橫移、後退、換目標、查Wiki

## 目標
- 核心目標：完成Check In與治療，賺取分數
- Check In成功得倒數獎金（最高200），治療得450-600
- 撐完整輪班得150分，發現異常得10分
- 避免扣分：亂走-20，貼牆-8，空按E-10，死亡-150
- 自訂目標需可量化、今日可達成，超時扣分
- 分數歸零於每輪班開始，歷史成績存檔

## 異常與危險
- 理智歸零即死亡，需立即退出重進
- 禁止購買任何付費物品（Robux、解鎖等）
- 地上手槍撿取會彈出購買視窗，需關閉且勿撿
- 異常判斷：比對本人與照片/CCTV，找顏色/物品差異
- 危險行為：亂走、貼牆、空按E、長時間無動作
- UI遮擋時需關閉，否則操作無效
- 視角頂到天花板/地板會卡住，需及時修正

## 資源與物品
- 咖啡機/杯用於恢復理智，需靠近互動
- 物品欄1-9鍵切換手持物品
- 相機、印章、文件為工作必需，需對準使用
- 道具使用：先
