# 我自己的遊戲手冊（09/13 13:34 自己整理）

## 基礎操作
- 滑鼠拖50像素轉約7度，100像素轉約14度，200像素轉約27度
- 按w 1秒移動量約27，按s 1秒移動量約100，按a/d約80-87
- 互動需先對準目標，畫面出現E提示才按，長按E約0.45秒有效
- 視角水平時dy填0，只轉dx；偏上往下修，偏下往上修，幅度40-80
- 貼牆卡住時，先s後退並look轉頭找路，確認視野開闊再移動
- UI面板開著時先關掉（找X或關閉按鈕），esc是最後手段
- 滾輪在清單是捲動，在遊戲畫面是縮放鏡頭，轉視角只能用look

## 遊戲模式
- 遊戲開始需在大廳選擇人多的伺服器加入，確認出現「輪班N」才算進入
- 理智歸零（死亡）或遊戲結束才可退出，其他情況卡住需在遊戲內解決
- 退出重進需重新確認遊戲身分，比對名稱、作者、封面，避免進錯遊戲
- 任務以右上角黑底白字為準，完成Check In與治療病人為主要循環
- 被重開後知識保留但位置推算歸零，需重新校準地圖與站位

## 地圖
- 主要區域：櫃檯窗口、走廊（門牌3-5, 5）、房間5、儲藏室、拍照區
- 咖啡機在左前方，咖啡杯在右前方桌上，需靠近後互動
- 拍照機位於拍照區，用於記錄異常證據
- 走廊連接各房間，注意門牌號碼對應房間
- 儲藏室出口需留意，避免誤入或卡住
- 地圖需自行腦中拼湊，利用記過的站位與方向校正位置

## 如何遊玩
- 輪班開始：確認狀態 -> 檢查UI -> 執行右上角任務
- Check In流程：走到櫃檯 -> 對準電腦/文件 -> 按E互動 -> 蓋印/登記
- 治療流程：接待病人 -> 檢查異常 -> 治療 -> 結案
- 異常處理：比對照片/CCTV -> 拍照存證 -> 通報異常
- 理智管理：低於20%去補理智（喝咖啡），補完立即回崗位
- 卡住處理：後退、橫移繞路、換方向、關UI，三分鐘無進展才考慮重進

## 目標
- 主要目標：撐過輪班，完成Check In與治療，獲取分數
- 分數來源：成功Check In/治療（遞減獎金）、發現異常、完成任務
- 扣分項目：死亡、亂走、空按E、貼牆、花錢、放棄任務
- 自我目標：設定可量化、可驗證的短期目標（如完成3次Check In）
- 避免偏袒：誠實評估任務難度與貢獻，不自訂虛高任務價值

## 異常與危險
- 異常判斷：比對本人與資料/照片/CCTV，注意顏色、位置、存在性變化
- 危險行為：撿手槍會彈購買視窗（禁止），理智歸零會死亡
- 禁止事項：絕對不花錢（Robux/金幣），不點自我復活
- 死亡處理：理智歸零後點「前往大廳」（免費），不點「自我復活」
- 異常處理：確認為異常後，按流程拍照、通報，避免誤判
