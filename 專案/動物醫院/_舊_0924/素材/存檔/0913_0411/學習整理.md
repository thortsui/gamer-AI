# 我自己的遊戲手冊（09/13 03:57 自己整理）

## 基礎操作
- 拖50像素轉7度，100像素轉14度，200像素轉27度
- 按w 1秒移動量27，s 100，a 80，d 87（0=被擋）
- 互動前必須看到E提示，沒提示按了無效
- 長按E需0.45秒以上，距離不夠需先靠近
- 視角水平時dy填0，只轉左右dx
- 滾輪在清單是捲動，在遊戲是縮放，轉視角只用look

## 遊戲模式
- 進遊戲先確認上方有「輪班N」且為第一人稱
- 理智歸零（死亡）才可退出，其他情況不准退出
- 卡住時在遊戲內解決：後退、橫移、換目標、關UI
- 退出重進需載入數分鐘，比在遊戲內解決更耗時
- 加入伺服器時挑人數多的場（看清單人數）

## 地圖
- 咖啡機在左前方，咖啡杯在右前方桌上
- 儲藏室出口、櫃檯窗口、拍照機、走廊入口已知
- 走廊門牌3-5、5、房間5、房間5電腦、拍照區已知
- 走到熟悉處需重新記位置校正座標，地圖靠記憶拼湊
- 手槍在地上，撿起會彈購買視窗，需按esc關閉

## 如何遊玩
- 唯一任務：一直做Check In，其他事暫放
- 操作前確認無UI遮擋，有則先關（找X或空白處）
- esc是開關，最後手段，易越按越糟
- 互動流程：aim對準 -> w靠近 -> 見E提示 -> 長按E
- 貼牆卡住：s後退 + look轉頭找路，確認視野開闊
- 任務目標：練熟互動成功率、移動有效率、減少卡住

## 目標
- 當前目標：練熟基本操作（互動、移動、視角）
- 追求高互動成功率、高移動有效率、低卡住次數
- 知識與地圖在重開後保留，但位置座標歸零需重記
- 確認位置後嚴格照右上角黑底白字任務執行

## 異常與危險
- 理智歸零=死亡，是唯一允許退出的情況
- 撿手槍觸發購買視窗，非任務物品，需關閉
- 椅子、病人本體、其他玩家、裝飾品不可互動
- 無E提示時互動無效，原因為未對準或不可互動
- 視角偏上/下時，依程式提示修正dy（40-80）

## 資源與物品
- 咖啡機在左前方，需長按E互動
- 咖啡杯在右前方桌上，aim後w靠近再長按E喝
- 手槍為危險物品，撿起會彈出付費視窗
- UI面板遮擋時優先找右上角X關閉
- 物品欄/道具使用需先確認無UI遮擋
