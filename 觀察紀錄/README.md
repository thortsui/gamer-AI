# 觀察紀錄

使用者 2026-09-27 交代：「這些都記錄好，我要看結果而且定期會去看」。
每 30 分鐘由監督排程追加一段到 `觀察紀錄/YYYY-MM-DD.md`，並推上 GitHub。每段包含：

- **A/B 指標**（`ab_stats.py`）：輪數、每輪秒、純上下%、沒動作%、進場、死亡、懲罰、斷線、最高輪班。總表在 `訓練資料/finetune/AB對照.md`。
- **每輪拆解**（`round_breakdown.py`）：每輪各環節（截圖／反射／組面板／快思／其他）平均幾秒與佔比。
- **工具**：他這段要了哪些工具、各幾次、每輪幾個。
- **腦內地圖**：我在／標點／到標點／走到／拍地標…用了幾次。
- **反射**：幾輪有跑、他喊換快思幾次。
- **子代理**：這個架構裡每輪由程式依序叫起的模型層（反射、快思、反射重問、慢想、各種檢討）；他自己不會開子代理。
- **登記**：報到成功累計次數。
- **他自己記的問題**：`{"t":"記問題"}` 寫進 `專案/<遊戲>/記憶/遇到的問題.jsonl／.md`。
