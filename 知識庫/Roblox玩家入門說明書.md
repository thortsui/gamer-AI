# Roblox 玩家入門說明書（給 AI 大腦讀的版本）

> 這份文件是給「gamer AI」的千問大腦當知識用的。
> 範圍：從什麼都不懂 → 裝好 Roblox → 基礎操作 → 找到遊戲 → 進入遊戲開始玩。
> 不含遊戲開發（Studio、Luau 腳本）；那些在 `D:\Documents\ThorWorkSpace\Roblox\` 專案裡。
> 適用平台以 **Windows 電腦** 為主，手機（iOS / Android）差異另外標註。
> 撰寫日期：2026-09-06。

---

## 0. 一句話認識 Roblox

Roblox 不是「一款遊戲」，而是一個**遊戲平台**：裡面有幾百萬款由玩家自己做的遊戲（官方叫「體驗 Experience」）。
你需要一個帳號、一個 Roblox 程式（Player），然後從平台裡挑一款遊戲點進去玩。
免費就能玩；遊戲內道具用的虛擬貨幣叫 **Robux**（要用真錢買）。

常見名詞對照：

| 名詞 | 意思 |
|---|---|
| Experience / 體驗 | 就是一款遊戲 |
| Place / 地點 | 一款遊戲裡的一張地圖或關卡 |
| Server / 伺服器 | 同一款遊戲會開很多間房，每間最多幾十人 |
| Avatar / 虛擬人偶 | 你在遊戲裡的角色外觀 |
| Robux | 平台貨幣，符號常寫成 R$ |
| Game Pass / 遊戲通行證 | 用 Robux 買的永久特權（例如雙倍金幣） |
| Spawn / 出生點 | 進入或死亡後重生的地方 |
| Obby | 跑酷跳台類遊戲（Obstacle course 的縮寫） |
| Tycoon | 經營建設類遊戲 |
| Simulator | 模擬器類，點擊收集升級的養成遊戲 |
| AFK | 掛機、暫離 |

## 1. 安裝 Roblox

### 1-1. Windows 電腦（兩種方式擇一）

**方式 A：官網（最通用）**
1. 打開瀏覽器到 `https://www.roblox.com`。
2. 先註冊或登入帳號（見第 2 節）。
3. 隨便點一款遊戲，按綠色的 ▶ **Play** 按鈕。
4. 第一次會跳出「下載並安裝 Roblox」，下載 `RobloxPlayerInstaller.exe` 執行。
5. 安裝完瀏覽器會問「要開啟 Roblox 嗎？」→ 按「開啟」。之後每次從網頁按 Play 都會自動啟動遊戲。

**方式 B：Microsoft Store**
1. 開啟 Microsoft Store，搜尋「Roblox」，按「取得」安裝。
2. 從開始功能表打開 Roblox App，裡面直接可以逛遊戲、按 Play。

兩種版本功能一樣。若網頁版按 Play 沒反應，通常是瀏覽器擋了「開啟外部程式」，重新裝一次或改用 Store 版即可。

### 1-2. 手機
- iPhone / iPad：App Store 搜尋「Roblox」。
- Android：Google Play 搜尋「Roblox」。
- 裝好打開 App → 登入 → 在 App 裡找遊戲 → 按 Play。

### 1-3. 系統需求（電腦）
- Windows 10 或 11。
- 網路要穩（線上遊戲，斷線就會被踢出伺服器）。
- 一般筆電內建顯示晶片就能跑，畫質可在遊戲內設定調低（見第 6 節）。

## 2. 帳號

### 2-1. 註冊
1. 到 `roblox.com` 首頁，填：生日、使用者名稱（Username）、密碼、性別（可略）。
2. 使用者名稱是**公開**的，會顯示在遊戲裡；不要用真名、不要含個資。
3. 建議之後到「設定 → 帳號資訊」補上 Email，忘記密碼才救得回來。

### 2-2. 登入
- 網頁右上角「登入」，或 App 開啟畫面的「登入」。
- 一個帳號可以同時登入網頁 + 遊戲程式，但**同一時間只能進一場遊戲**。

### 2-3. 未滿 13 歲的帳號
- Roblox 會依生日自動套「兒童模式」：聊天會被過濾更嚴、部分內容分級較高的遊戲看不到。
- 家長可設 PIN 碼鎖住設定，避免小孩自己改年齡或關掉限制。

### 2-4. 帳號安全
- 密碼不要跟別人講，**Roblox 官方永遠不會私訊問你密碼**。
- 有人說「免費 Robux 點這裡」「幫你儲值」→ 一律是詐騙。
- 建議在「設定 → 安全性」開啟兩步驟驗證。

## 3. 主畫面怎麼看

打開 `roblox.com` 或 Roblox App 登入後，左邊有一排選單：

| 選單 | 用途 |
|---|---|
| **首頁 Home** | 推薦遊戲、最近玩過、好友在玩什麼 |
| **探索 / Discover（舊稱 Games）** | 依分類逛全部遊戲，有搜尋框 |
| **虛擬人偶 Avatar** | 換衣服、換臉、換動作 |
| **好友 Friends** | 好友清單、加好友 |
| **訊息 Messages** | 站內信 |
| **商店 Marketplace（舊稱 Catalog）** | 買衣服、配件 |
| **Robux** | 儲值 |
| 右上角 **齒輪 ⚙** | 設定、登出 |

### 3-1. 一張遊戲頁面上有什麼
點進任何一款遊戲會看到：
- **綠色大按鈕 ▶ Play**：進遊戲。
- **遊戲名稱、作者、遊玩人數（Active）、造訪次數（Visits）**：人數越多通常越熱門。
- **說明 Description**：作者寫的玩法介紹，**進遊戲前先讀一下**，很多操作說明寫在這裡。
- **商店 Store** 分頁：這款遊戲的通行證與道具。
- **伺服器 Servers** 分頁：可以挑一間特定的房間進去，或看好友在哪一間。
- **年齡分級**：「全年齡」「9+」「13+」「17+」，帳號年齡不夠會看不到或不能玩。

## 4. 找一款遊戲

### 4-1. 用搜尋
探索頁上方的搜尋框輸入名字（中英文都可）。熱門遊戲舉例：
- **Adopt Me!**：養寵物、佈置家。
- **Brookhaven RP**：角色扮演、開車逛城市。
- **Blox Fruits**：戰鬥冒險、練等。
- **Tower of Hell**：跑酷 Obby。
- **Pet Simulator 99**：點擊收集寵物模擬器。
- **Grow a Garden**：種田養殖。
- **Doors**：恐怖解謎。

### 4-2. 用分類
探索頁會分「推薦」「熱門」「最高評分」「角色扮演」「冒險」「格鬥」等，直接往下滑。

### 4-3. 跟好友一起
- 首頁上方會顯示好友頭像和「正在玩 xxx」，點頭像 → **加入 Join** 就會進到跟他同一間伺服器。
- 也可以進遊戲後開好友清單，選好友 → 加入。
- 或是遊戲頁面「伺服器」分頁 → 你的好友正在哪一間會列出來。

### 4-4. 挑遊戲的小訣竅
- 看**遊玩人數**：幾千人以上的通常比較穩、不會是空房。
- 看**評分**（讚 / 倒讚比）：低於 70% 的踩雷機率高。
- 看**更新日期**：太久沒更新可能壞掉。
- 名字裡寫「免費 Robux」「Free Robux」的一律不要碰，是詐騙。

## 5. 進入遊戲

1. 在遊戲頁面按 ▶ **Play**。
2. 瀏覽器會問「開啟 Roblox？」→ 按開啟（Store 版和手機直接開）。
3. 出現 Roblox 的載入畫面（黑底、進度條），一般 10～60 秒，看網路和遊戲大小。
4. 有些遊戲會先出現**大廳 Lobby**（選關卡、選隊伍、選角色），有些直接把你丟到地圖上。
5. 看到你的角色站在地上、右上角有聊天框或選單，就代表**已經在遊戲裡了**。

**進不去的常見狀況：**

| 畫面 | 原因 | 怎麼辦 |
|---|---|---|
| 「Roblox 已在執行中」 | 上一場沒完全關掉 | 工作管理員結束 `RobloxPlayerBeta.exe` 再按 Play |
| 錯誤碼 277 / 279 / 17 | 網路斷線或連不到伺服器 | 檢查網路，等 1 分鐘再試，或換一間伺服器 |
| 錯誤碼 267 | 被該遊戲踢出（作弊偵測或遊戲腳本踢人） | 換一款或重新進入 |
| 錯誤碼 524 | 那間伺服器只讓好友進 | 從遊戲頁面重新按 Play 進公開房 |
| 一直卡在載入畫面 | 遊戲太大或電腦太慢 | 等 2 分鐘；還不行就關掉重進，並把畫質調低 |
| 「此體驗不可用」 | 遊戲被下架，或年齡不符 | 換一款 |

## 6. 基礎操作（電腦鍵盤 + 滑鼠）

這是 Roblox **預設**的操作，絕大多數遊戲都通用；個別遊戲會加自己的按鍵（通常寫在遊戲說明或畫面上）。

### 6-1. 移動

| 按鍵 | 動作 |
|---|---|
| **W / A / S / D** | 前 / 左 / 後 / 右 走 |
| **方向鍵 ↑↓←→** | 也可以移動（部分遊戲拿去當別的用途） |
| **空白鍵 Space** | 跳 |
| **Shift**（部分遊戲） | 跑步（預設沒有，是遊戲自己加的） |
| **Shift**（預設） | 「Shift 鎖定」：按一下切換，角色面向會跟著滑鼠轉，適合射擊和戰鬥 |
| **/** 或 **Enter** | 打開聊天輸入框 |
| **Esc** | 開遊戲選單（設定、離開、回報） |
| **Tab** | 顯示玩家名單（部分遊戲） |
| **數字鍵 1～9、0** | 切換工具列上的道具（背包） |
| **`**（反引號，Tab 上面那顆） | 打開 / 收起背包（Backpack） |

### 6-2. 視角（相機）

| 操作 | 動作 |
|---|---|
| **按住滑鼠右鍵拖曳** | 轉視角 |
| **滑鼠滾輪** | 拉近 / 拉遠（拉到最近會變成第一人稱） |
| **I / O 鍵** | 拉近 / 拉遠（和滾輪一樣） |
| **Shift 鎖定開啟時** | 不用按右鍵，滑鼠直接轉視角，畫面會出現一個小準心 |

相機模式在 Esc 選單裡可以改：
- **Classic 傳統**：要按右鍵才轉，滑鼠可以自由點畫面上的按鈕。
- **Follow 跟隨**：相機自動跟著角色方向。

### 6-3. 互動
- **滑鼠左鍵**：使用手上的工具（揮劍、開槍、點擊）；沒拿工具時通常沒作用。
- **E 鍵**：最常見的「互動」鍵（開門、撿東西、跟 NPC 講話）。畫面上會出現「按 E」或一個圓圈提示。
- **靠近會出現的按鈕（ProximityPrompt）**：走到物件旁邊，畫面浮出「E ／ 互動」提示，按 E 或按住 E。
- **點擊物件（ClickDetector）**：有些東西滑鼠移上去會變手指游標，直接左鍵點。

### 6-4. 聊天
- 按 **/** 打開輸入框，打字後 Enter 送出。
- 左上角聊天框可以捲動看歷史。
- 聊天有自動過濾（髒話、數字、個資會被打成 ####）。
- 有些遊戲的聊天框裡打 `/e dance`、`/e wave` 可以做表情動作（跳舞、揮手）。

### 6-5. 背包與工具
- 畫面下方一排格子叫**工具列（Hotbar）**，按數字鍵 1～0 選用。
- 選了工具，角色手上會拿著，左鍵使用。
- 按 **`**（反引號）打開完整背包，可以把道具拖到工具列。
- 再按同一個數字鍵會收起工具。

### 6-6. 重生 / 復活
- 死亡後通常 5 秒自動在出生點重生。
- 卡住的時候：**Esc → Reset Character（重置角色）** 會立刻死亡並重生（會掉手上的東西，看遊戲設計）。

| 畫面元件 | 動作 |
|---|---|
| **左下角虛擬搖桿** | 移動 |
| **右下角跳躍按鈕** | 跳 |
| **在畫面空白處滑動** | 轉視角 |
| **兩指捏合** | 拉近 / 拉遠 |
| **點物件** | 互動（等同滑鼠左鍵） |
| **下方工具列** | 點格子切換道具，再點畫面使用 |
| **左上角聊天泡泡** | 開聊天 |
| **左上角 Roblox 圖示** | 開選單（相當於 Esc） |

手機上 Roblox 的 emoji 圖示會顯示成空心方塊，這是正常現象。

## 8. 遊戲內選單（Esc）

按 Esc（手機點左上角 Roblox 圖示）會出現：

| 分頁 | 內容 |
|---|---|
| **Players 玩家** | 這間伺服器所有人，可以加好友、封鎖、檢舉 |
| **Settings 設定** | 畫質（Graphics Quality）、音量、相機模式、Shift 鎖定開關、全螢幕 |
| **Report 檢舉** | 檢舉玩家或這款遊戲 |
| **Help 說明** | 按鍵一覽表 |
| **Reset Character 重置角色** | 卡住時用 |
| **Leave 離開** | 退出這場遊戲回到主畫面 |

**遊戲卡頓時**：Settings → Graphics Mode 改「Manual」→ Graphics Quality 拉到最低 1～3 格。

## 9. 玩遊戲的一般流程（給 AI 的決策骨架）

一款陌生的 Roblox 遊戲，通常這樣摸索：

1. **先讀遊戲頁面的說明**（Description）——很多遊戲的核心玩法和按鍵都寫在那。
2. **進遊戲後先看畫面**：
   - 左上 / 右上通常是**金錢、等級、任務**。
   - 畫面中間浮出的文字是**教學提示**，照著做。
   - 下方是**工具列**。
   - 地圖上會有**發光 / 箭頭 / 圓圈**指引你去哪。
3. **找 NPC 或看板**：走過去按 E，新手任務通常從這裡開始。
4. **先做最便宜的升級**：模擬器 / Tycoon 類遊戲，第一件事是找「Shop」「Upgrade」把最便宜的買下來。
5. **死掉不用怕**：大多數遊戲死亡只是回出生點。
6. **看別的玩家在做什麼**：人多的地方通常就是重點區域。
7. **不確定就開聊天問**：「how to start?」或「怎麼玩」多半有人回。
8. **要走就 Esc → Leave**，遊戲進度大多會自動存檔（有存檔系統的遊戲）。

常見遊戲類型對應的目標：

| 類型 | 核心迴圈 |
|---|---|
| Simulator 模擬器 | 點擊 / 收集 → 賣出換錢 → 買升級 → 解鎖新區域 → 重複（Rebirth 轉生會重置但加倍率） |
| Tycoon | 站在按鈕上花錢蓋東西 → 產生收入 → 蓋更多 |
| Obby 跑酷 | 從起點跳到終點，每一段有檢查點（Checkpoint） |
| RP 角色扮演 | 沒有勝負，選職業、開車、和人聊天 |
| 戰鬥 / 射擊 | 找武器、打敵人或殭屍、守波次 |
| 恐怖解謎 | 找鑰匙、開門、躲怪 |

## 10. 安全與禮儀

- 不要把真名、學校、住址、電話、其他平台帳號打在聊天裡。
- 不要點別人貼的網址、不要下載「外掛」「腳本」（會被封號，也常是病毒）。
- 有人騷擾：Esc → Players → 那個人 → **Block 封鎖** 或 **Report 檢舉**。
- 交易道具只走遊戲內建的交易介面，「先給我我再給你」的一律是騙。
- 遊戲裡的 Robux 商品要花真錢，買之前先跟大人確認。
- 對別人有禮貌：不罵人、不亂殺隊友、不擋路。

## 11. 常見問題速查

| 問題 | 答案 |
|---|---|
| 為什麼按 W 不會動？ | 可能聊天框開著（按 Esc 關掉），或視窗沒被點到（點一下遊戲畫面） |
| 為什麼滑鼠一直轉視角、點不到按鈕？ | Shift 鎖定開著，按一下 Shift 關掉 |
| 為什麼看不到自己的角色？ | 滾輪拉太近變第一人稱了，往後滾 |
| 為什麼有的遊戲找不到？ | 帳號年齡不夠該遊戲的分級，或遊戲已下架 |
| 為什麼道具不見了？ | 大多數遊戲重生會清掉臨時道具，或那是「單局限定」 |
| 遊戲當掉沒反應？ | 等 30 秒；還是不行就 Alt+F4 關掉重開 |
| 怎麼換伺服器？ | Esc → Leave → 遊戲頁面 → Servers 分頁選另一間 |
| 怎麼跟朋友同一間？ | 好友清單點他 → Join |
| 怎麼看自己的 Robux？ | 網頁 / App 右上角的 Robux 圖示 |
| 語言想改中文？ | 網頁右上角 ⚙ → 設定 → 語言；遊戲內文字看該遊戲有沒有做翻譯 |

## 12. 給 AI 大腦的回答原則

當玩家問 Roblox 相關問題時：
1. **先判斷玩家在哪個階段**：還沒裝？裝了沒帳號？進不去？進去了不會操作？
2. **一次只給下一步**，不要把整份手冊倒給他；小朋友看太多字會放棄。
3. **按鍵用大寫字母寫**（W、E、Shift、Esc），並說明「在鍵盤哪裡」。
4. **手機和電腦分開回答**，先確認他用什麼裝置。
5. **遇到錯誤碼**，對照第 5 節表格。
6. **有人問免費 Robux、外掛、腳本** → 明確說那是詐騙或會封號，不提供方法。
7. **不知道特定遊戲的細節時**，引導他「讀遊戲頁面的說明」和「看畫面上的提示」，不要編造按鍵。
8. 回答用**繁體中文、台灣用語**，可以用一點 emoji 但不要太多。
