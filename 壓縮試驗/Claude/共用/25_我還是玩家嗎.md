【每一輪先確認：我現在還是「玩家本人」嗎？】
遊戲會把你變成別的狀態（死掉、被附身、旁觀、鏡頭被鎖在某樣東西上），那時你按什麼都沒反應。
- **是玩家本人**：按 w／a／d 畫面會跟著移動；物品欄還在；這隻遊戲「正常遊玩中」固定顯示的標記還在（是什麼要你自己看出來、記下來）。
- **不是玩家本人**（出現任何一項就先這樣當）：那個遊玩中標記不見了；出現 出口／Exit／離開／遊戲結束／失敗／觀戰／旁觀 的字或按鈕；看的是別的東西的視角（相機、螢幕、模型）；按 w／a／d 完全沒反應但畫面自己會動；物品欄不見或 UI 整個換一套。
- **分不出來就測一次**：`{"t":"key","k":"w","d":0.5}`。畫面往前推進＝是本人；完全沒變＝被介面或機台固定住（改用 look／click），或已經不是本人。

【失敗／結束時：出口按鈕就是給你按的】
- 失敗、死亡、一局結束、變旁觀時出現的 出口（Exit／離開）可以按，不花錢。順序：確認不是本人 → 點出口 → 回大廳 → 重新加入 → 確認又是本人 → 繼續。
- 一局進行中、還在正常遊玩時不要點離開，卡住就在遊戲裡換做法。但不在局內、又在同一個狀況卡住（無法移動、找不到出口或進場的路、滑鼠不見／游標鎖住解不開、按鈕按不動）就可以退出重進，不用等「完全動不了」（2026-09-23 使用者定）。
- 永遠不准點「復活」「購買」「解鎖」那種要花錢的。
- 重進前比對【你記過的遊戲身分】：名稱、作者、封面特徵、進入步驟，四項都對才加入。

【先認識自己長什麼樣】
- 看得到自己的身體或背影＝第三人稱：游標自由，點得到 UI；轉視角要按住右鍵拖。
- 看不到自己（頂多看到手）＝第一人稱：滑鼠鎖在中央當準心，點不到 UI。
看得到自己時送 `{"t":"記自己","樣子":"顏色、頭長怎樣、手上拿什麼、身高比例"}`（程式連畫面一起存）。之後可以：判斷人稱；看自己相對背景有沒有動來確認真的移動了；不把畫面中央那個又大又近的自己當目標按 E。
