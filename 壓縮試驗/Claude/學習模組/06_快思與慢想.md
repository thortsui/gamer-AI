章節: §9 決策骨架
適用: 全部

【名詞】主任務＝做一道菜；大動作＝挑菜／洗菜／切菜／下鍋炒（有頭有尾、做完看得到結果）；細步驟＝拿菜、放到水裡、搓、沖乾淨、瀝乾（小到可以直接做）。

【三層分工】（2026-09-20 使用者定案；反射那一層 09-29 更正）
| 層 | 看得到什麼 | 負責什麼 |
|---|---|---|
| **反射** | 基礎操作的儀表（視角、標點、按鈕簿、畫面上的字、短期記憶）＋快思交代的上一步 | 只檢查上一步有沒有正常執行（`ok`），不決定動作、不改計畫 |
| **快思** | 基礎操作＋這個大動作的文檔＋現況 | 把現在這個大動作切成做得出來的細步驟（`寫步驟`），並直接給三步的動作。不重排整個序列 |
| **慢想**（不趕時間） | 全部（含學習模組、任務樹、四面環顧） | 排大動作序列（主任務 → 大動作 1、2、3…），並把現在這一個切好 |

【快思直接出三步，反射只檢查】（2026-09-29 使用者更正）
- 快思每次回答，除了這一輪的 a，還要給 `步:[①,②,③]`：現在這一步、接著那一步、然後那一步，每一步附動作 JSON 與「做完會看到什麼」（`成`）。①當場做。
- 反射只看畫面回答上一步有沒有正常執行：做成了 → 程式直接做②、再做③；沒做成（或畫面跟這一步對不上、跳出沒看過的東西、被傳送、死掉）→ `{"t":"換快思"}` 重排。三步做完也回到快思。
- 每一步都要小到「照著做不用想」；「成」要寫畫面上看得到的變化。做完大動作的一步，把 `{"t":"這步做完"}` 放進那一步的 a 裡。
- 好的三步具體到現在就能動手、做完看得出成敗：「轉到面朝東（現在面朝北，往右轉 90 度）」「直走兩秒到走廊底」「站定後左右各掃一次」；「找到那個地方」「把任務做完」是願望不是步驟。用【目前視角】的度數和 X／Y 來寫，不要用「往那邊」。

【寫步驟】
```
{"t":"寫步驟","大動作":"進場","目的":"讓畫面從大廳切到關卡",
 "步驟":["拉遠解鎖滑鼠","點字開始","等2秒讀新出現的字","點確認","站上踏板等畫面切換"]}
```
`目的`一句話，讓反射知道什麼情況算「這幾步不管用了」。

【慢想】
快思負責把身體移動好、解決眼前的小問題；方向（等一下去哪、這條路對不對）交給慢想。慢想決定去哪，快思決定怎麼過去，方向定了快思就不要重選。
- 每隔十二輪，程式給你兩分鐘想：我現在在哪；等一下要去哪、為什麼；上一步做了什麼、有沒有效；接下來怎麼做。
- 慢想排的是（09/14 改）：現在的大動作＋它的詳細步驟＋下一個大動作。寫進【慢想排出來的計畫】，每輪都看得到：總共幾步、你在第幾步、做完接著是什麼。
- 每輪把 👉 那一步往前推一點；做完送 `{"t":"下一步"}`；最後一步也做完、或計畫走到一半發現不對（路是死的、目標不在那裡、根本不在那個地方）送 `{"t":"重想"}`，程式給一次不限時的慢想。

【步數預算】（2026-09-21、09-22 使用者定）
用 `寫步驟` 把大動作切成 N 步，預算＝N×2 輪（一步最多兩輪），程式從那一刻數輪數。
- 預算內：面板告訴你已用幾輪、還剩幾輪；做完只印一行紀錄，不加分。
- 超過 N×2 輪：扣 3 分（之後每多拖 3 輪再扣一次），並當場檢討一次。
- 一步的標準是兩輪內做得完。太細：「修水平」「轉頭朝北」「再轉一點對準」「往前一小步」；剛好：「轉頭朝北並走到配對電梯踏板上」「點開始遊戲並等地圖面板出現」。
- 超支時選一條、不要拖：這一步其實做到了 → 馬上送 `{"t":"這步做完"}`；根本做不到 → 送 `{"t":"寫步驟","大動作":"…","步驟":[更少的步驟]}` 重切成更少、更大塊。

【學會之後拆成工作流程】（2026-09-27 使用者交代）
一件事做成過一次就寫下來，每一步小到照著做不用想，而且知道上一步、下一步是什麼：
- 整串：`{"t":"排大動作","主任務":"這一局要達成什麼","序列":["進場","做飯","收拾"]}`
- 某個大動作：`{"t":"寫步驟","大動作":"做飯","步驟":["洗菜","切菜","下鍋","調味","盛盤"]}`
- 做完一步送 `{"t":"這步做完"}`，整個大動作做完送 `{"t":"大動作完成"}`。
面板的【大動作】會告訴你現在第幾步、上一步做了什麼、下一步要做什麼。照流程一步步往前走時，程式會跳過例行的慢想（每 12 輪那一次），只有卡住才叫慢想重排。發現順序錯了就用 寫步驟 改掉。

【進場是必要的大動作】
每一局都要做、每次都一樣：把細步驟寫下來（`寫步驟`）照著跑；穩定了用 `{"t":"錄成程序","名":"進場","秒":180}` 錄成程式。
