---
章節: §8 遊戲內選單（Esc）
適用: 全部
---

【每一輪先確認有沒有 UI 開著】
畫面上蓋著面板／視窗／選單／對話框，就先關掉，不然按什麼、走什麼都沒反應。關掉後再看一次畫面確認真的關了。

【面板是誰的、怎麼關】（2026-09-26 使用者交代）
- **遊戲的面板**：跟這款遊戲有關的字（任務、商店、職業、開始、確認…），關法看它自己的叉叉或按鈕。
- **Roblox 自己的面板**：每款遊戲都一樣，不會幫你推進任何事，裡面沒有「開始」「職業」。三種：
  1. 好友選單／玩家個人卡：中央一塊面板，有玩家名字、頭像或人偶，「加好友」「檢視個人資料」「封鎖」「檢舉」。點到別的玩家（人偶或名字）就會跳出來。
  2. 玩家列表：一排玩家名字、頭像、分數，通常在右上或整片蓋住。
  3. esc 選單：左側「玩家、設定、協助、帳號…」分頁，右下角有「繼續」。
- **關的順序（一次一招，沒關掉換下一招，不要對同一個座標連點）**：①面板右上角的叉叉（X）②面板上寫「繼續／關閉／返回」的字（esc 選單用右下角「繼續」）③esc 只按一下（它是開關，按第二下又打開；一直按 esc 永遠出不來）④點面板以外的空白處。
- 選單開著時先讀按鈕上的字，它會寫哪個鍵對應什麼（繼續／離開／重生）；用滑鼠點或按它標示的鍵。
- 常駐在畫面邊緣的按鈕列（左側一排小圖示、上方的名字與數字）不是遮罩，不用關也關不掉；只有蓋在中央、擋住 3D 畫面的才要關。
- 不要一直打開它：人多的地方不要對著玩家點左鍵；點按鈕前先用【畫面上的字】確認那個位置是按鈕的字，不是玩家名字。

【點了沒反應，先當作「你沒按好」】
同一顆按鈕多試幾次再放棄：點正中央、稍微偏一點、按久一點、等畫面穩定一秒再點。常見原因：點到邊緣、按太短、畫面還在切換、上面蓋著另一塊面板。試幾次都沒反應才換做法。

【第一人稱時滑鼠被吃掉——先試十字能不能點】（2026-09-23 使用者教的）
1. 轉視角把十字對到按鈕上按左鍵（`{"t":"click","x":0.5,"y":0.5}`）——有反應就是十字游標模式，以後都這樣點。
2. 沒反應才是真的鎖住：滾輪拉遠變第三人稱，或把介面關掉再開一次，再點。
3. 拉遠幾次都解不開、按鈕怎麼都按不動＝同一個狀況卡住，直接退出重進（見「卡住就自己重開遊戲」）。

【學習階段：UI 要讀完再關】
教學視窗、提示框、彈出來的說明是遊戲唯一會主動教你的東西，關掉就沒有第二次。先用【畫面上的字】把字整段讀完；讀到「按什麼鍵會怎樣」「先做什麼再做什麼」當場記（記因果／列步驟）；確定沒東西要記才關。不要為了趕快開始就連點關閉。

【看得到不等於點得到】
遊戲視窗可能比螢幕大或有一部分在螢幕外，滑鼠到不了。【碰不到的區域】會告訴你哪幾塊點不到，程式也會擋掉點在那裡的動作。改用：鍵盤（Enter／空白鍵／數字鍵／Esc／方向鍵）；走過去按 E；捲動清單、關掉再開、換一個入口，把目標弄到碰得到的區域。

【一次只做一件事，一次只按一個鍵】
不要連點，也不要一輪同時送「轉視角＋走路＋點擊」：畫面切換途中那一下會落在新畫面的別的東西上，也分不出是哪一件造成的結果。節奏：送一個動作 → 等畫面穩定（需要就 `{"t":"wait","d":1.0}`）→ 看字、按鈕、場景有沒有變 → 有變照新畫面走，沒變才換做法再試。

【按鈕簿：同一顆按鈕點第二次就把位置記起來】（2026-09-18 使用者定）
程式自動記帳：你每點一下，它看畫面有沒有變，把「名字 → 座標 → 會跳出什麼 → 有反應／沒反應幾次」寫進按鈕簿，每輪回灌：
```
✅ 開始遊戲：(0.43,0.05)　在「大廳」 會跳出：（新出現的字）　有反應 3 次
⚠ 左邊圖示：(0.05,0.30)　有反應 0 次／沒反應 2 次
```
- ✅＝成功過三次以上，直接用。⚠＝點很多次都沒反應：不是按鈕或現在不能按，換做法（先關掉擋住的、先拉遠解鎖滑鼠、換入口），不要再點同一個位置。
- 自己也可以寫：`{"t":"記按鈕","name":"開始遊戲","x":0.43,"y":0.05,"畫面":"大廳","效果":"跳出選地圖"}`。x／y 不寫就用上一次點的位置；`效果`寫按下去會發生什麼。

【按完每一顆 UI，一定要讀字】（2026-09-20 使用者定）
按完按鈕，下一輪提示最上面會有（反射輪也看得到）：
`🔎 你剛才按了「開始」→ 多出來的字：（…）。先讀完這些新字再決定下一步` 或 `🔎 你剛才按了「開始」，畫面上的字完全沒變——那一下沒有生效。`
- 字變了 → 讀新字，照著走下一步（新出現的「確認」「下一步」就是下一顆要按的），不要回頭重按第一顆。
- 字沒變 → 沒生效，不要再點同一個位置：先 `scroll -3` 拉遠解鎖滑鼠、先關掉擋住的面板、或走到地上的觸發區站上去。
