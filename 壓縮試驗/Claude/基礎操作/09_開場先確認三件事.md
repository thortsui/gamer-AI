章節: §6-0 開場先確認三件事（每次登入都要做一次）
適用: 全部
---

【每次登入／重進之後，先確認完這三件事再做別的】（2026-09-18 使用者定的基礎工作流）
答案由你自己看畫面得到。

**第一件：現在是第幾人稱？**
- 正中央有準心、看不到自己＝第一人稱，點不到 UI。看得到自己的背影在畫面下方中央＝第三人稱，點得到 UI。
- 切換：`{"t":"scroll","v":-3}` 拉遠（→第三人稱）、`{"t":"scroll","v":3}` 拉近。
- 順手把視角修到水平（做法見【視角】），讓背影回到畫面下方中央。
- 記下來：`{"t":"記知識","檔":"基礎操作","內容":"這個遊戲登入後預設是第X人稱；拉遠 N 格會變第三人稱"}`

**第二件：要開始遊戲，去哪裡、按什麼？**
入口有三種，確認這一款是哪一種：按鈕（用點字點）；觸發區（地上的發光板、圈圈、箭頭、電梯、平台，要走上去站著才跳 UI，見【踩到哪裡會跳出什麼】）；兩段式（先站上去跳面板，再點「確認」）。
確認方法：走過去、站一秒、看畫面有沒有變。確認完把整條路記下來：
```
{"t":"記因果","做了":"走到地上的發光方板站著","發生":"跳出下一步的面板"}
{"t":"標點","name":"進場踏板","樣子":"地上白色發光方板","前":2}
{"t":"錄成程序","名":"進場","秒":180}          ← 成功進場的當下馬上錄
```

**第三件：這一局要用到哪些能力／按鍵？**
進場後在安全的地方（大廳、準備時間）先花幾輪搞清楚：下方物品欄幾格、數字鍵 1~9 各拿出什麼；左鍵、右鍵做什麼；E 是互動還是撿東西；R、F、Q 和其他鍵有沒有作用；狀態條、計時器、階段、金錢各在哪一角。試出一個記一個：
`{"t":"記知識","檔":"基礎操作","內容":"右鍵＝瞄準；E＝互動；數字鍵 1 拿第一格的東西"}`

每次登入都重對一次（幾輪就好）：視角、入口、按鍵。對不上＝遊戲更新了或你進錯地方，先弄清楚再玩。
