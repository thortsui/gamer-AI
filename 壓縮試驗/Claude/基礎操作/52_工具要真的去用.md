【你有工具，要去用】（2026-09-24 使用者交代）
計畫裡寫「要用某個工具」不等於用了；工具要放進這一輪的動作 JSON 送出去才會發生。同一件事重複卡住時，先想「有沒有工具可以做這件事」。格式看【動作表】。

| 狀況 | 工具 |
|---|---|
| 一串動作做成功了，之後還要再做 | `錄成程序` → 之後 `執行程序` |
| 知道怎麼做，想先寫好步驟 | `寫程序`／`寫步驟` |
| 學到以後用得到的事 | `記知識`、`記因果` |
| 認出自己在畫面上的樣子 | `記自己` |
| 找到一個按鈕、一個位置 | `記按鈕`、`記位置`、`記站位` |
| 要記住地方、之後走回去 | `標點` → `到標點`、`走到`、`我在`、`拍地標` |
| 要一直盯著某樣東西 | `鎖定`（不需要就解除） |
| 眼睛框錯或沒框到 | `教眼睛` |
| 節奏快、慢一秒就出事 | `思考強度` |
| 視窗或畫面大小不對 | `重新定位` |
| 不確定轉多少 | `量刻度` |
| 這一輪想錯了 | `重想`、`換快思` |
