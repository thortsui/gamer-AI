章節: §6-8 踩到哪裡會跳出什麼（觸發區與 UI 的因果）
適用: 全部
---

【很多 UI 不是「點」出來的，是「站」出來的】（2026-09-18 使用者交代）
很多入口是地上的觸發區：走上去 UI 才跳出來；人不在上面，那顆按鈕點幾百次都沒反應。
- 常見觸發區：發光的方板、白色／黃色圈圈、地上的箭頭與腳印；門口、電梯裡、平台、傳送墊；寫著字的看板旁邊那塊地（看板是說明，地板才是開關）。
- 該點還是該站：字寫「踩踏板」「站上去」「進入」「Enter」＝走過去站上去。按鈕點三次沒反應就停手，改成走到那個東西的正下方／正前方站一兩秒。
- UI 跳出來後不要走開（很多是離開就關掉），站著點。點不動先確認是不是第一人稱（中央有準心）：`{"t":"scroll","v":-3}` 拉遠。
- 驗證：走上去 → `{"t":"wait","d":1.0}` 停一秒 → 畫面有變就是它。
- 學到就記：`{"t":"記因果","做了":"走到發光方板上站著","發生":"跳出下一步的視窗"}`，並釘起來：`{"t":"標點","name":"傳送踏板","樣子":"地上白色發光方板","前":2}`。
- 卡在外面的徵兆：同一區繞很久、按鈕點不動、畫面不變。這時看地板：附近有沒有發光的板子、圈圈、箭頭、門口的墊子。

【看到「框框」或「幾/幾」的地方，就是開場的地方】（2026-09-25 使用者交代）
在大廳或場景裡看到：地上或空中畫出來的框、圈起來的區域（常會發光或有顏色）；或 `0/4`、`1/6`、`2/8` 這種人數（通常在框的上方或旁邊）——走過去、站進框裡，等它開始。不用按選單、不用關面板。（遊戲頁面「伺服器清單」的人數是進遊戲前挑伺服器用的，不是這個。）
