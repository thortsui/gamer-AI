---
章節: §8 遊戲內選單（Esc）
適用: 全部
---

【每一輪先確認有沒有 UI 開著】
動作前先看畫面有無面板／視窗／選單／對話框。有則先關，否則無反應。
關 UI 順序：1. 右上角叉叉(X)。2. 面板上「關閉／返回／繼續」按鈕。3. 點面板外空白。4. esc 最後（esc 是開關，易反覆）。
關後確認畫面真的乾淨才繼續。

【選單怎麼關掉】
esc 是開關，連按會反覆。選單開著時看按鈕標示文字（如「繼續」「離開」），用滑鼠點或按對應鍵。點空白處通常也能關。

【點了沒反應，先當作「你沒按好」】
同一按鈕至少多試幾次再放棄。常見沒按好：點偏、按太短、畫面切換中按、被面板蓋住。
再試：點正中央、偏一點、按久點、等畫面穩定。試幾次無反應才是真不能按，換做法。

【第一人稱滑鼠被鎖——先試十字點】
第一人稱滑鼠鎖中央，點按鈕常無效。但有些遊戲十字即滑鼠（2026-09-23 使用者教）。
順序：1. 十字對準按鈕按左鍵 `{"t":"click","x":0.5,"y":0.5}`，有反應即此模式。2. 無反應則拉遠變第三人稱（滾輪／中鍵）或關介面重開。3. 拉遠無效即卡住，退出重進。

【學習階段：UI 讀完再動】
教學視窗是遊戲唯一主動教學，關掉無第二次。看到面板先：1. 整段讀完字（用【畫面上的字】）。2. 記下按鍵因果與步驟。3. 確認無須記才關。勿急關，否則需自試幾百輪。

【看得到不等於點得到】
遊戲視窗可能超出螢幕，滑鼠到不了。程式會在【碰不到的區域】標記並擋掉該處動作。
見標記勿硬點，改用：鍵盤（Enter/空白/數字/Esc/方向）、走過去按 E 互動、捲動清單或換入口讓目標進可碰區。

【一次只做一件事】
勿連點、勿一輪塞多動作。連點易誤觸新畫面；多動作致畫面不同步。
節奏：1. 送一個動作。2. 等穩定（需則 `{"t":"wait","d":1.0}`）。3. 看結果。4. 有變照新畫面走，沒變換做法。做完一件再做下一件，否則無法歸因。

【按鈕簿：記位置與效果】（2026-09-18 使用者定）
按鈕位置固定，第一次點到後記下，之後照抄。程式自動記帳：名字→座標→反應次數，每輪回灌。
✅＝成功過三次以上，可靠。⚠＝多次無反應，非按鈕或不可按，換做法勿再點同處。
自寫格式：`{"t":"記按鈕","name":"開始遊戲","x":0.43,"y":0.05,"畫面":"大廳","效果":"跳出選地圖"}`。x/y 缺省用上次位置。記座標省試錯輪次。

【按完 UI 必讀字】（2026-09-20 使用者定）
按完看字變：新字是下一步，舊字是已關。程式自動比對，下一輪頂部顯示 `🔎 你剛才按了「X」→ 多出來的字：...` 或 `字完全沒變`。反射輪亦可見。
字變：讀新字，照著走下一步，勿重按第一顆。字沒變：勿再點同處，換做法（scroll -3 解鎖、關面板、走觸發區）。

【UI 功能對照】
按鈕簿記「會跳出什麼」，即 UI→功能表。自補：`{"t":"記按鈕","name":"確認","x":0.5,"y":0.75,"效果":"按了之後畫面切換"}`。價值在知道帶去哪，非僅座標。

【認識 Roblox 面板】（2026-09-26 使用者交代）
面板分遊戲與 Roblox 兩種。Roblox 面板（好友選單、玩家列表、esc 選單）不推進遊戲，勿當入口。
關法順序：1. 右上角 X。2. 「繼續／關閉」按鈕。3. esc 按一下。4. 點空白。關後確認，未關換招。
常駐邊緣按鈕列非遮罩，勿關。防誤開：人多處勿點玩家，點按鈕前用【畫面上的字】確認非玩家名。
