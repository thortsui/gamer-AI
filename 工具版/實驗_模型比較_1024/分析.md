抽樣看到的差別（細節在 每輪紀錄.jsonl）：
- **本地 27B**：描述偏通用（「中央角色擋直走」「沒看到E框」），10 輪裡 7 輪「上一輪實際」寫被擋／量不出，幾乎不寫座標；HUD 數字讀得到。
- **Haiku**：會列物件和座標（紫色拍照機 E 框 (0.41,0.37)、印表機紅點 (0.24,0.49)），看得到「已註冊」螢幕字；但 16% 的輪 JSON 壞掉（想太長，慢想 xhigh 思考 token 一小時 57 萬）。
- **Sonnet**：讀得出螢幕內容（「DNA結果／DUKE GREEN／流感」）、藥櫃上的分類（眼藥水、點滴袋）、倒數牌 17S、2/5；會用 確認人稱 判斷中央角色是不是自己，結論跟程式量測一致。
- **原生**：每個物件都給座標和距離（「藥櫃 (0.25,0.30) 約 2 個身高」「綠葉＝草藥」），「上一輪實際」直接引用程式量測數字（「轉 15 實測只左移 3%，預期約 12%」），E 框「關閉」會自己判斷不按（會把門關回去）。

## 結論

1. **模型本身的智力明顯影響成功率和產出。** 同樣的工具與資訊：兩步全符合 本地 29～37% → Haiku 25% → Sonnet 43% → 原生 67%；遊戲任務推進 Sonnet 走到從沒人到過的「分析樣本／治療」（採集樣本本地也到過），原生一小時大任務完成 4 次（本地 4.5 小時 0 次）。
2. **圖片判斷：Sonnet 系列讀得出畫面上的字和物件用途**（螢幕病名、藥櫃種類、倒數牌），本地和 Haiku 多半只認出「有 E 框／被擋」。程式的量測（二次驗證）四個差不多（80～94%），差別在「看懂畫面、把量測結果用對」。
3. **速度：快不一定是想得少就差。** Haiku 想最久（中位 64 秒、思考 token 最多）卻最差且常輸出壞 JSON；Sonnet 28 秒、原生 14 秒反而最準。
4. **記憶（不洗掉）是第二大因素。** 同樣是 Sonnet，原生（整小時同一個 session）第 2 步預測 54%→80%、全符合 43%→67%、每輪快一倍（快取＋不用每輪重新理解局面）。代價是費用：上下文一路長到 96.8 萬 token（最後 1 輪自動壓縮成 3.3 萬），四段費用 $2.66→$4.01→$4.86→$5.85，越後面越貴。
5. **自由搜尋沒有被用到**：原生版有 WebSearch／WebFetch 但 0 次，這次看不出搜尋的影響。
6. **量測的老問題跟模型無關**：視角移動到 轉完位移的二次驗證，四個都低（本地 10/13、Haiku 4/11、Sonnet 2/6、原生 3/15）。

## 不公平／要扣掉的地方
- **遊戲現場無法還原**：記憶還原了，但 Roblox 的狀態（在大廳或局內、理智、別的玩家）接續上一個模型。Sonnet、原生是接在前一個推進過的局面上開始，Sonnet 開場理智 3% 就死。
- **問 Claude 的待遇不一樣**：Haiku 08:20 那題我答了（指出蓋印表格的位置，有實際幫助），08:54 那題在換模型時被還原掉、沒答到；Sonnet 09:52 那題同樣沒答到；原生 10:09 那題 28 分鐘後才答、而且只說不確定。監督只在 :25/:55 看，換模型時記憶還原會把沒答的題目清掉——下次實驗要在還原前先看。
- 一個模型只跑一小時、一次，沒有重複；抽樣判斷是我人工看文字紀錄（沒有逐輪截圖存檔），屬參考。
- 原生版多了 Claude Code 原本的 system 和讀檔工具，資訊並非完全一樣（但它沒用 Read／Glob／Grep，工具紀錄 0 次）。
- 本地是微調過的 27B、跑在 DGX；Claude 走雲端。速度比較包含網路與主機差異。

→ **只換 system 不會讓它想得少（B 反而想更多）；想得少來自「同一個 session 記得前面」**（C 越後面越少）。離線用同一張圖、動作不會真的發生，所以記憶的效果比實戰小。

### 結論（原生多很多的原因，照影響大小）
1. **開場狀態不公平**：Sonnet 開場理智 3% 馬上死、花 24 分鐘重新配對進局；原生開場就在病房旁邊。光這點，Sonnet 有效時間只剩約 35 分鐘。
2. **記憶（同一 session）**：不用每輪重新理解局面 → 思考少 4 倍、每輪快一倍 → 輪數多一倍；而且越跑越準（53%→78%），第 2 步預測特別準（記得剛剛做了什麼、會發生什麼）。
3. **多用 描述畫面 當筆記**：78 次，輸出留在對話裡，後面的輪拿來用。
4. Claude Code 原本的 system **不是**原因（對照測試 B 沒有比 A 好）。
5. 代價：上下文一路長到 97 萬 token、費用每 15 分鐘從 $2.7 漲到 $5.9。
