# 提示/ — 系統提示的模組（照《Roblox 玩家入門說明書》的章節拆好）

跟 `工作流程/*.md` 一樣：**內容放檔案，程式只負責載入**。
每一輪程式會照「現在是什麼情境」挑出要載入的幾份，接起來當成送給模型的 system 提示。

改檔案就生效，**不用重開代理**（程式用檔案修改時間判斷要不要重讀）。

## 檔案格式

```
---
章節: §6-2 視角（相機）        ← 對應基礎遊玩手冊的哪一節（純備註）
適用: 全部                     ← 什麼情境才載入；多個用「、」或「,」分開
停用: 是                       ← （選填）填「是」就整份不載入
---

正文……（JSON 範例直接寫 {"t":"look","dx":150,"dy":0}，不用跳脫大括號）
```

正文裡可以用這幾個參數，程式會換成當下的實測值：
`{game}`、`{ppp}`（拖幾像素≈畫面轉 1%）、`{deg_px}`（轉 1 度≈dx 多少）、
`{max_dx}`、`{max_dy}`（單次上限）、`{quarter}`（四分之一畫面的 dx）。

## 「適用」可以填的情境

| 情境 | 什麼時候成立 |
|---|---|
| `全部` | 每一輪都載入 |
| `遊戲中` / `遊戲外` | 程式查前景視窗是不是 Roblox |
| `櫃檯作業` / `非櫃檯作業` | 程式判定他被固定在櫃檯前（按 w/a/d 沒反應）時 |
| `認識櫃檯` / `熟悉櫃檯` | 站位＋掃描＋至少 3 樣設備記齊了沒 |
| `流程:報到` | 他現在做的流程（`流程:治療`、`流程:喝咖啡`…同理） |
