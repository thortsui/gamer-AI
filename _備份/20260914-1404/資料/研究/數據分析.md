### 8.1 決策模式（有 click、有首字秒／決策秒／總秒）

```json
{"時間": "02:06:03", "模式": "決策", "差異": 0.5, "看到": "看到蓋印表格機器，紅點閃爍", "robux": 0, "動作": [{"t": "click", "x": 0.46, "y": 0.45, "g": "蓋印表格機器"}], "擋掉": [], "筆記": "蓋印表格互動點在機器上的紅點", "截斷": false, "首字秒": 1.64, "決策秒": 3.23, "prompt_tokens": 2679, "總秒": 3.72}
```

| 欄位 | 值 | 意思 |
|---|---|---|
| 時間 | 02:06:03 | 這一輪開始的時刻（HH:MM:SS） |
| 模式 | 決策 | 正常的「看畫面 → 決定動作」輪 |
| 差異 | 0.5 | 與上一輪截圖的灰階平均差；0.5 表示畫面幾乎沒變，所以不用先「看清楚」 |
| 看到 | 看到蓋印表格機器，紅點閃爍 | 模型對畫面的一句描述 |
| robux | 0 | 沒偵測到付費視窗 |
| 動作 | click (0.46, 0.45) 目標「蓋印表格機器」 | 實際執行的動作；x/y 是螢幕比例座標（0–1），g 是模型宣稱的點擊目標，供程式做關鍵字過濾與看圖確認 |
| 擋掉 | [] | 這輪沒有動作被安全層擋下 |
| 筆記 | 蓋印表格互動點在機器上的紅點 | 模型寫給研究筆記.md 的一條學習 |
| 截斷 | false | 模型回覆完整、沒被字數截斷 |
| 首字秒 | 1.64 | 送出請求到收到第一個 token 的秒數（網路＋排隊） |
| 決策秒 | 3.23 | 送出到整段回覆收完的秒數（首字 1.64 ＋ 生成 1.59） |
