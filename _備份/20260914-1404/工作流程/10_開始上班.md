# 開始上班（人還在醫院外面的大廳時）

**怎麼知道自己在大廳**：畫面上方**沒有**「輪班 N」，是第三人稱（看得到自己的背影），
左邊有商店／邀請／職業／日誌那排按鈕，可能還看得到 0/4、2/4 這種人數。

**在大廳最重要的一件事**：這裡沒有病人、沒有櫃檯、沒有咖啡機——**唯一該做的是回醫院上班**。
不要在大廳找櫃檯、不要按「離開」（在大廳按離開＝退出整個遊戲）。

## 步驟

1. **先關掉蓋住畫面的東西**：Roblox 自己的選單／好友面板／「確定要離開遊戲？」對話框。
   - 對話框問你要不要離開 → 點「**不要離開**」。
   - 面板 → 點它右上角的**叉叉 X**，或點面板外的空白處。
   - **不要一直按 esc**（它是開關，你會自己把選單開開關關）。
2. **確認是哪一隻遊戲**：照【你記過的遊戲身分】比對名稱、作者、封面。**絕對不能進錯遊戲**。
3. **挑人多的場**：遊戲頁面往下捲有伺服器清單，每個都寫著人數（6/8、3/8）——挑人數多的加入。
   直接按大大的播放鍵常常會被丟進空場。用 `{"t":"scroll","v":-3}` 往下捲。
4. **加入之後確認真的進去了**：畫面上方出現「**輪班 N**」、切成第一人稱（看不到自己的身體）。
   - 有 → 你開始上班了，照【這一班的計畫】做事（有病人就報到，沒病人就治療）。
   - 沒有 → 你還在大廳或進錯地方，回第 2 步重來。
5. 進去之後先**確認自己在哪**：看得到櫃檯嗎？走到櫃檯工作位（看【你現在在哪、櫃檯設備在你的哪一邊】）。

## 常見錯誤

- 在大廳一直想關面板、一直按 esc → 越按越多視窗。點叉叉或點空白處。
- 把大廳當成 Roblox 首頁又去點 Play → 程式每輪會告訴你現在是什麼畫面，以它為準。
- 進錯遊戲 → 一定要先比對遊戲身分再加入。

## 大廳裡關不掉的東西：那是看板，不是 UI

大廳的牆邊有一塊**排行榜看板**（寫著「最高轉移速度」和一排玩家名字），
它是**場景裡的 3D 物件**，不是視窗——**沒有叉叉、按 esc 也關不掉**。
2026-09-10 你曾經對著它按了 41 次 esc、耗掉整整 30 分鐘。

**怎麼分辨**：轉一下視角。
- 東西**跟著畫面一起移動** → 場景物件（看板、螢幕、告示、電視）→ **轉身走開就好**。
- 東西**釘在畫面上不動** → 才是真的 UI 面板 → 才需要關。

同理：大廳左邊的商店／邀請／職業／日誌是 UI 按鈕（不會動），
而牆上的招牌、排行榜、告示牌都是場景。

## 大廳到底怎麼進去上班

大廳（place 78515283254292）跟醫院（place 104522435597696）是**兩個不同的場**，
所以「進去上班」＝**在大廳裡找到入口走進去**，讓遊戲把你傳送過去。

- 要找的是 **ANIMAL HOSPITAL 那棟建築的入口**：門、玻璃門、電梯、或發著光的門口。
- 走進去之後畫面上方會出現「**輪班 N**」，那才代表你真的開始上班了。
- 大廳裡的商店／邀請／職業／日誌都**不會**讓你開始上班，別在那邊繞。
- 找不到門的時候：先看【畫面外的東西在哪】有沒有記過 door／entrance，
  沒有就原地左右掃一圈（只轉左右），看到門就用 `走到` 讓程式帶你過去。
